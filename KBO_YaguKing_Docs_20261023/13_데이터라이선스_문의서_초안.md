### KBO 리그 경기·기록 데이터 이용 라이선스 문의

**수신**: 스포츠투아이㈜ 〔데이터 사업 담당 부서 또는 담당자〕
**참조**: (사)한국야구위원회
**발신**: 〔운영 주체명〕 〔이름·직함〕
**일자**: 〔발송일〕

---

#### 1. 문의 취지

〔운영 주체명〕은 KBO 리그 팬을 위한 야구 지식 퀴즈 서비스 '야구왕'을 개발하고 있습니다.
이 서비스에 KBO 리그의 경기 결과·순위·기록 데이터를 이용하고자, 정식 이용 조건과 절차를
문의드립니다.

KBO 홈페이지 이용약관(2024년 2월 26일 시행)을 확인하였습니다. 제14조는 귀사의 사전 서면
동의 또는 KBO가 제공하는 공식 API 없이 자동화 수단으로 데이터를 수집하는 것을 금지하고,
제17조는 사전 동의 없는 상업적 이용을 금지하고 있습니다. 저희는 이 조항에 따라 **현재까지
KBO 홈페이지의 데이터를 자동으로 수집하지 않았으며**, 정식 동의 또는 라이선스를 받은 뒤에
데이터를 이용하려 합니다.

현재 서비스 문항은 KBO 리그 규정 문서와 일반 야구 상식만으로 제작하고 있습니다. 경기
결과나 선수 개인 기록은 쓰지 않고 있습니다.

#### 2. 서비스 소개

| 항목 | 내용 |
|---|---|
| 서비스명 | 야구왕 |
| 형태 | 웹 서비스 (모바일·태블릿·PC) |
| 핵심 방식 | 야구 지식 문제를 '투구'로, 정답 속도를 '타구 결과'로 바꾼 1이닝 퀴즈 경기 |
| 이용자 | KBO 리그 팬. 비회원 체험 + 회원 기록 저장 |
| 현재 단계 | 〔예: 소규모 시범 공개 준비 중 / 공개 예정 시기〕 |
| 예상 이용자 규모 | 〔예: 시범 기간 중 일 이용자 ○명 내외〕 |
| 수익 모델 | 〔예: 현재 없음 / 광고 예정 / 유료 기능 예정 — 사실대로 기재〕 |

#### 3. 이용을 희망하는 데이터

| 구분 | 데이터 | 우선순위 |
|---|---|---|
| ① | 경기 일정·결과(스코어, 경기 상태: 우천 취소·서스펜디드 등) | 높음 |
| ② | 팀 순위 | 높음 |
| ③ | 선수 시즌 기록(타격·투구 주요 지표) | 중간 |
| ④ | 경기별 기록(박스스코어 수준) | 중간 |
| ⑤ | 과거 시즌 기록(연도별 팀·선수 기록) | 중간 |

정규시즌과 포스트시즌을 대상으로 하며, 퓨처스리그는 필요하지 않습니다. 〔필요하면 수정〕

#### 4. 이용 목적과 방식

**가. 서비스 내 '최신정보' 표시**
회원 홈 화면과 경기 결과 화면에 전날 경기 결과, 당일 일정, 팀 순위를 보여 드리려 합니다.
모든 정보에 기준 시각과 출처를 표기하며, 표기 문구는 귀사가 정하신 조건을 따르겠습니다.

**나. 퀴즈 문항 제작 (2차 가공)**
경기 결과와 기록을 바탕으로 퀴즈 문항을 만들려 합니다. (예: "어제 ○○전에서 결승타가 나온
이닝은?") 모든 문항은 출제 전에 운영자가 사람의 눈으로 검수하며, 문항마다 출처와 기준일을
기록합니다. 이 용도가 2차 가공에 해당하므로, 허용 여부와 조건을 특히 여쭙고자 합니다.

**다. 하지 않을 것**
- 데이터를 재판매하거나 제3자에게 제공하지 않습니다
- 받은 데이터를 다른 서비스가 가져갈 수 있는 형태(API·파일 내려받기 등)로 다시 공개하지 않습니다
- 허락받지 않은 로고·엠블럼·선수 사진을 쓰지 않습니다
- 라이선스 범위 밖의 데이터를 수집하지 않습니다

#### 5. 기술적 사항

- **갱신 주기**: 경기 종료 후 2시간 이내 반영을 희망합니다. 하루 3회(경기 종료 후 밤 1회,
  다음 날 아침 정정 확인 1회, 낮 일정 확인 1회) 정도의 수신을 예상합니다
- **호출량**: 저희 서버가 정해진 시각에 한꺼번에 받아 자체 데이터베이스에 저장하고, 이용자
  화면은 저희 데이터베이스만 읽습니다. **이용자 수가 늘어도 귀사로 가는 요청은 늘지 않습니다**
- **형식**: API, 정기 파일 전송, 웹훅 등 귀사가 제공하시는 방식에 맞추겠습니다
- **정정 반영**: 기록 정정이 있으면 다음 수신 때 반영합니다
- **보관과 삭제**: 귀사가 정하신 보관 기간을 지키고, 계약이 끝나면 받은 원본 데이터를 삭제합니다

#### 6. 여쭙고 싶은 사항

1. 위 데이터를 제공받을 수 있는 경로(제휴 계약, 공식 API 등)와 담당 부서
2. 제공 가능한 범위(3항의 ①~⑤ 중 어디까지)와 경기 종료 후 제공 시점
3. 제공 형식(API 인증 방식과 호출 한도, 파일 전송, 웹훅)
4. **퀴즈 문항 제작(2차 가공) 허용 여부와 조건**
5. 출처 표기 문구, 로고 사용 가능 여부, 노출 위치에 관한 조건
6. 데이터 보관 기간과 계약 종료 시 처리 방법
7. 광고나 유료 기능이 있는 서비스에서 이용할 때의 조건과 비용 구조
8. 시범 운영(소규모 공개) 단계에 적용할 수 있는 조건이나 시범 기간 제도

#### 7. 회신 요청

담당 부서를 안내해 주시거나 위 사항에 회신 주시면 감사하겠습니다. 서비스 소개 자료와 화면
예시를 추가로 드릴 수 있으며, 필요하시면 화상 또는 대면 미팅으로 설명드리겠습니다.
