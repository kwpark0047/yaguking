# 야구왕 — 화면별 상세 UI/UX 명세 (V1)

> **이 문서는 `08_야구왕_V2_UI_UX_화면설계.md`로 대체되었습니다.** V2가 유효한 기준이며, 본 문서는 V1 기준선 보존용입니다. 단 S10~S13(실시간 방·경기)과 S20(관리자)은 P3 구현 시점까지 본 문서의 명세를 계속 참조합니다. 폐기: S04·S05(최초 레벨 테스트).

- 기준: PRD v1.0
- 디자인 방향: 한국 프로야구의 스코어보드 감성 + 현대적 모바일 게임 UI. 특정 구단 공식 로고·유니폼 디자인은 권리 확인 전 사용 금지.
- 반응형: 모바일 360px+, 태블릿, 데스크톱. 모바일 하단 탭 홈/대결/랭킹/마이, 데스크톱 좌측 사이드바.

## 1. 디자인 시스템

기본 글꼴: 한국어 가독성 우선(시스템 폰트/Noto Sans KR 대체). 8px 기반 간격, 카드 radius 12~16px, 버튼 높이 최소 44px, 높은 대비, 다크모드. 정답·오답은 색만으로 표현하지 않고 아이콘과 텍스트를 병기. 카운트다운은 숫자와 시각적 진행률 병행. 애니메이션은 `prefers-reduced-motion` 대응.

## 2. 화면 목록과 상세 상태

### S01 `/` 랜딩/비회원 체험
- 헤더: 브랜드, 로그인, 도움말.
- 히어로: `야구를 얼마나 안다고?`, `[바로 퀴즈 시작]`, `[친구와 대결]`.
- 오늘의 5문제, 역대 레전드 퀴즈, 구단별 팬 대항전 미리보기, 공개 랭킹.
- 체험 완료 후 결과·공유 링크·가입 CTA. 최초 화면에 가입 강요 금지.
- 상태: 비로그인/로그인, 오늘의 퀴즈 완료/미완료, 로딩/실패.

### S02 `/auth` 로그인
- 구글·카카오·이메일 중 실제 설정 완료된 공급자만 표시.
- 약관/개인정보 동의 분리, 로그인 오류·중복 계정 안내, OAuth 리다이렉트 복원.
- 성공 시 미완료 온보딩으로, 완료 회원은 대시보드로.

### S03 `/onboarding` 회원 프로필
- 단계1 닉네임(2~16자·중복 확인); 단계2 최애 구단 1·2·3(1순위 필수, 중복 불가); 단계3 최애 선수 1·2·3(선택, 선수명 검색/생년·소속 표시); 단계4 확인.
- 선택 변경·이전·건너뛰기·임시 저장. 팀 변경 시 팬 대항전 반영 정책 안내.
- 성공 시 최초 레벨 테스트 시작 CTA.

### S04 `/placement` 최초 레벨 테스트
- 상단 `7/20`, 남은 시간, 영역 라벨, 진행바.
- 질문 카드와 보기 A/B/C/D. 한 번 제출하면 변경 불가. 15초 종료 시 무응답 처리.
- 문제별 정답 즉시 공개 여부: **최초 배치 테스트는 종료 전 정답 비공개**(문제 유출 방지).
- 새로고침 복원, 오프라인 안내, 만료 처리, 제출 중 버튼 비활성화.

### S05 `/placement/result` 초기 레벨
- 레벨 배지, 정답 수, 5영역별 정답률, 공유용 인증 카드(개인정보 최소화).
- CTA `[첫 공식 퀴즈]`, `[친구에게 도전]`.
- 중복 결과 조회는 기존 완료 결과 표시.

### S06 `/dashboard` 홈 대시보드
- 닉네임·Lv·XP 진행바·대표 구단·최애 선수.
- 오늘의 퀴즈, 친구 대결, 오답 복습, 최근 5게임, 개인 랭킹.
- 레벨 테스트 미완료 배너, 복습 예정 알림, 네트워크 오류 상태.

### S07 `/quiz` 모드 선택
- 개인/데일리/친구 대결 탭. 카테고리·난이도·문제 수 선택.
- 시작 전 제한시간·보상·유효 랭킹 여부 설명.

### S08 `/quiz/play/[id]` 개인 퀴즈
- 문제, A~D 보기, 남은 시간, 현재 점수, 연속 정답.
- 제출 후 서버 판정 결과·해설·출처 표시, 다음 문제.
- 탭 전환/새로고침 복원, 만료·중복 제출·연결 끊김 메시지.

### S09 `/quiz/result/[id]` 개인 결과
- 점수, 정답률, 평균 응답시간, XP, 오답 목록, 공유 카드.
- CTA `[오답 복습]`, `[다시 도전]`, `[친구 도전장]`.

### S10 `/rooms/new` 방 만들기
- 방 이름, 10문제 기본, 15초, 난이도, 최대 2~10명, 공개/비공개.
- 생성 후 코드와 링크 복사, 카카오톡 공유(Web Share API/공유 SDK 사용 조건 확인).

### S11 `/rooms/[code]` 대기실
- 초대 코드, 참가자 아바타/닉네임/준비 상태, 방장 배지, 방 설정.
- 2명 이상 준비 시 방장 시작 활성화. 정원 초과/만료/시작 후 입장 제한 안내.
- 방장 이탈 시 새 방장 표시. 재접속 중 상태 안내.

### S12 `/battle/[id]` 실시간 경기
- 서버 기준 공통 타이머, 문제 카드, 4보기, 본인 제출 상태.
- 제출 중 타 참가자의 정답 비공개. 공개 단계에서 정답·설명·문항별 점수·현재 순위.
- 접속 끊김 시 재접속 버튼 및 경기 상태 복원. 종료 후 결과 이동.

### S13 `/battle/[id]/result` 대결 결과
- 1~10위, 총점, 정답률, 개인 XP, MVP 표시, 재대결·공유.
- 동점 규칙: 정답률 → 평균 응답시간 → 먼저 최종점수 도달 순.

### S14 `/rankings` 랭킹
- 개인/구단 탭, 일·주·시즌·전체 필터, 나의 순위 고정 영역.
- MVP는 공식 점수 기반; RP 탭은 2차 출시 전 노출하지 않음.
- 구단 랭킹은 참여자 수·평균 유효 점수·집계 기간 명시.

### S15 `/wrong-answers` 오답노트
- 전체/미복습/복습 완료, 카테고리/난이도/기간 필터.
- 문제, 내 답, 정답, 출처, 다음 복습 예정일. `[복습 시작]`.
- 1·3·7·14일 간격, 연속 2회 정답 숙달.

### S16 `/review/[id]` 오답 복습
- 보기 4개, 답안 판정, 해설, 복습 단계 표시.
- 동일 문제 반복 XP 제한과 복습 완료 보상 안내.

### S17 `/profile/[id]` 프로필
- 공개 범위 설정, 레벨, 대표 구단, 선호 선수(동의한 정보만), 배지, 게임 성과.
- 타인 방문 시 비공개 통계·오답·계정 정보 숨김.

### S18 `/settings` 설정
- 프로필 수정, 선호 팀/선수 수정, 알림, 계정 삭제/내 데이터, 개인정보 처리방침.
- 이벤트 중 대표 구단 변경 시 점수 소급 미반영 안내.

### S19 `/promotion` 승급 시험 — 2차
- 목표 레벨, XP 충족 여부, 합격 점수, 24시간 재응시 쿨다운.

### S20 `/admin` 관리자 — 운영 MVP
- 문제 생성/검수/게시/정정, 출처·버전 확인, 신고, 부정행위 검토, 감사 로그.
- 관리자 역할은 서버 검증. 운영 페이지와 일반 회원 API 권한 분리.

## 3. 공통 컴포넌트

`AppShell`, `BottomNav`, `AuthGuard`, `TeamSelector`, `PlayerSearchSelect`, `QuestionCard`, `AnswerOption`, `Countdown`, `ScoreBoard`, `LevelBadge`, `XPProgress`, `LeaderboardTable`, `WrongAnswerCard`, `ShareChallengeCard`, `EmptyState`, `ErrorState`, `LoadingSkeleton`, `ConfirmDialog`, `Toast`.

## 4. UX 예외 흐름

- 서버가 응답을 받지 못했을 때 재시도 전 `GET state`로 확정 여부 확인.
- 제출 후 브라우저 새로고침 시 중복 답안 생성 금지.
- OAuth 복귀 시 원래 초대 링크를 보존.
- 친구 초대 링크는 유효기간과 방 상태에 따라 적절한 안내.
- 시간 만료 시 화면 타이머보다 서버 판정 우선.
- 데이터 없음·검색 결과 없음·네트워크 오류·권한 없음·관리자 정정 안내를 모두 설계.

## 5. 접근성 및 QA

키보드 전체 조작, 명확한 focus 표시, 스크린리더 레이블, 충분한 대비, 44px 터치 타깃, reduced motion, 360px 화면에서 가로 스크롤 방지, 다크모드. E2E: 온보딩 4단계, 20문제 중단 복원, 친구 초대 입장, 오답 복습, 타인 비공개 정보 차단.
