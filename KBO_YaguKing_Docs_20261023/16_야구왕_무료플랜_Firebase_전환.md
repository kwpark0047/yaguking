# 야구왕 — 무료 플랜(Firebase Spark) 전환

- 작성일: 2026-10-26 · 상태: **개발 0~8단계 완료, 배포 전**(실제 Firebase 프로젝트·원격 저장소 없음)
- 관계: 01~15 문서의 **플랫폼 부분을 대체**한다(Supabase·Vercel·서버 판정 → Firebase Spark·보안 규칙·예약 작업).
  기획·게임 규칙·콘텐츠 원칙은 01~15를 그대로 따른다. 충돌하면 이 문서가 우선한다(§4)
- 코드: `firebase-app/` (기존 Next.js + Supabase 앱 `..`은 지우지 않고 그대로 둔다)
- 자세한 기록: `firebase-app/README.md`(단계별), `firebase-app/docs/`(데이터 구조·사용량·공식 XP 설계·배포·검증 보고서)

---

## 0. 한 줄 결론

유료 서비스 없이 **Firebase Spark 무료 플랜만으로** 로그인·프로필·개인 퀴즈·레벨 테스트·오답노트·친구 대결을 만들었다.
서버 코드가 없어 **모든 점수는 비공식**이다(기기가 채점). 공식 XP·랭킹은 GitHub Actions 예약 작업이 판정하는 설계만 있다.
배포 설정은 끝났지만 **배포는 사용자 승인 전이라 하지 않았다.**

## 1. 왜 바꿨나 — 지킨 제약

사용자 지시(2026-10-26, "야구왕 무료 플랜 개발·배포 전환"):

| 제약 | 어떻게 지켰나 |
|---|---|
| Supabase, Vercel, 유료 API, 유료 호스팅을 쓰지 않는다 | Firebase Hosting·Authentication·Cloud Firestore(Spark)만 |
| Firebase Blaze로 전환하지 않는다 | 결제 계정 연결 없음. TTL·Cloud Functions·Storage처럼 결제가 필요한 기능 안 씀 |
| Cloud Functions·결제 필요 기능을 쓰지 않는다 | 서버 쪽 방어선 = Firestore 보안 규칙. 관리 작업 = GitHub Actions(꺼짐) |
| 실제 KBO 기록을 권한 확보 전 자동 수집하지 않는다 | 문제은행은 기존 CSV(`data/`)만. 수집 코드 없음 |
| 기기가 조작할 수 있는 점수는 공식 랭킹에 넣지 않는다 | 모든 점수·XP·등급을 "비공식"으로 표시. 공식 문서 경로는 규칙이 기기 쓰기를 막음(테스트) |
| 기존 파일을 임의 삭제·덮어쓰지 않는다 | 새 폴더 `firebase-app/`. 기존 코드는 복사만(`COPIED_FROM.md`). 01~15 문서는 본문을 고치지 않고 머리에 안내만 덧붙임 |
| 실제 배포 전 사용자 승인 | 배포하지 않음. 배포 워크플로는 꺼짐 + 승인 단계(`firebase-app/docs/deploy.md`) |

## 2. 무엇이 바뀌었나

| 영역 | 기존(01~15) | Firebase판 |
|---|---|---|
| 앱 | Next.js App Router, 서버 라우트 | Vite + React 정적 사이트(Firebase Hosting) |
| 데이터 | Supabase PostgreSQL + RLS, 마이그레이션 | Cloud Firestore(서울 `asia-northeast3` 예정) + 보안 규칙(`firestore.rules`) |
| 인증 | Supabase Auth, 게스트 쿠키(`yk_guest`) | Firebase Authentication: 이메일·비밀번호, 구글, **익명**(비회원). 가입 = 계정 연결(uid 유지) |
| 판정 | 서버가 정답·시간 판정, 정답 비노출 | **기기가 판정(비공식)**. 문제은행은 정적 JSON으로 앱에 들어감(읽기 비용 0, 정답 노출 감수) |
| 공식 XP·랭킹 | 서버 원장 | 설계만 — GitHub Actions 일꾼 판정, 문제 하나씩 열기(`docs/official-xp-rp.md`) |
| 실시간 대결 | 서버 상태 머신(2차) | Firestore 실시간 구독, 각자 속도로 풀기, 비공식 |
| 보관 기간 파기 | DB 함수 + 크론 + 안전망 | `ops/cleanup.mjs`(관리자 권한) — GitHub Actions 예약(꺼짐) 또는 운영자 PC |
| 배포 | Vercel, 수동 승인 게이트 | Firebase Hosting, 배포 직전 자동 점검, 미리보기 채널 → 승인 → 실제 |
| 비용 한도 | 서버 비용 | 하루 읽기 5만·쓰기 2만·삭제 2만, Hosting 하루 360 MB(`docs/usage-report.md`) |

## 4. 기존 문서별로 달라지는 점

본문은 그대로 두고 아래만 바뀐 것으로 읽는다. 각 문서 머리에 이 표로 오는 안내를 붙였다.

|---|---|---|
| 01 PRD | 게임 규칙, XP 표·레벨 임계값, 처음 테스트 등급(정답 수 → Lv1~5), 비회원 하루 2판, 만 14세 | §7 "모든 공식 정답·점수·시간은 서버 판정" → 지금은 전부 **비공식**. 공식은 7단계 설계(공식전) 승인 뒤. 소셜 로그인은 구글만(카카오 없음) |

## 5. 그대로인 원칙

정답·기록 기준일과 출처 표기, 실제 KBO 기록 자동 수집 금지, 만 14세 미만 가입 불가, 성별 등 불필요한 정보 미수집,
보관 기간은 지킬 수 있는 값만, 15초 제한·복습 간격·동점 규칙, 접근성(axe critical/serious 0).
