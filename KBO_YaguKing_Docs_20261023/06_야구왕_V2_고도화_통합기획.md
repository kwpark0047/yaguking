## 1. 한 줄 요약

> **퀴즈를 "경기"로 바꾼다.** 문제는 투구, 정답 속도는 타구, 오답은 아웃. 3아웃이면 1이닝이 끝나고 **박스스코어**가 남는다. 그 기록을 저장하고 **내 구단의 오늘 승리에 반영하려면** 그 자리에서 가입한다.

차별화의 축은 두 개다.

1. **게임 문법 자체를 야구로 교체** → 설명 없이 이해되고, 결과물이 `타율 / OPS / 박스스코어`라는 야구팬 전용 화폐로 축적된다.
2. **혼자 푼 문제가 구단의 승패로 집계되는 상시 팬 페넌트레이스** → 개인 랭킹이 아니라 부족(tribe) 경쟁이 리텐션을 만든다.

## 3. 설계 원칙 (V2)

1. **첫 화면에서 첫 투구까지 0탭.** 랜딩 페이지의 히어로가 곧 1번 타석이다. 로그인·약관·모달·튜토리얼을 앞세우지 않는다.
2. **가입은 "저장"의 대가로만 요구한다.** 플레이를 막는 벽이 아니라, 이미 만든 기록을 지키는 행위로 제시한다.
3. **야구 문법으로만 말한다.** 점수·레벨·랭킹을 득점·등급·타율로 환산해 야구팬에게는 설명이 필요 없게, 라이트 유저에게는 애니메이션으로 유추되게 만든다.
4. **혼자 플레이도 집단에 기여한다.** 모든 공식 타석은 구단 팬덤 집계에 들어간다.
5. **정확성은 콘텐츠 신뢰의 전부.** 기록 기준일 명시, 출처 없는 문항 게시 금지(V1 승계).

## 4. 핵심 게임 루프 — "1이닝"

### 4.1 기본 문법

| 야구 요소 | 게임 매핑 |
|---|---|
| 투구 | 문제 1개 제시(4지선다, 15초) |
| 타격 결과 | **정답 여부 + 서버 측정 응답시간**으로 결정 |
| 아웃 | 오답 또는 시간초과 |
| 이닝 종료 | **아웃 3개** |
| 득점(R) | 주자가 홈을 통과한 수 |
| 타율·출루율·장타율 | 통산 누적 기록으로 영구 보존 |

### 4.2 타석 판정표 (서버 전용)

| 조건 (t = 서버 측정 응답시간) | 결과 | 진루 | 타수(AB) |
|---|---|---|---|
| 정답, t ≤ 2.0s | **홈런 (HR)** | 주자 전원 + 타자 득점 | 포함 |
| 정답, 2.0s < t ≤ 4.5s | **2루타 (2B)** | 2베이스 | 포함 |
| 정답, 4.5s < t ≤ 8.0s | **단타 (1B)** | 1베이스 | 포함 |
| 정답, 8.0s < t ≤ 15.0s | **볼넷 (BB)** | 1베이스 강제진루만 | **제외** |
| 오답 | **아웃 (삼진 K)** | 변동 없음 | 포함 |
| 무응답(15.0s 초과) | **아웃 (루킹 삼진)** | 변동 없음 | 포함 |

**결과 승급 규칙** — 아래 조건 충족 시 결과가 한 단계 상승한다(`BB → 1B → 2B → 3B → HR`).

- 난이도 `고급` 문항 정답
- 연속 정답 5개 이상 유지 중

> 승급은 **타석당 최대 1단계**로 상한한다(두 조건을 동시 충족해도 1단계). 따라서 **3루타는 승급 경로로만 발생**하는 희귀 결과가 되어 연출 가치가 생긴다.

설계 의도: 고급 문항을 고르는 쪽이 유리하고, 빠르게 맞출수록 보상이 커지며, 느려도 볼넷으로 출루해 "완전 실패"가 아니다. 속도 보너스가 숫자가 아니라 **장면**으로 보인다.

### 4.3 모드 구성

| 모드 | 길이 | 비회원 | 공식 집계 | 용도 |
|---|---|---|---|---|
| **체험 1이닝** | 3아웃 (약 60~90초) | 가능 (1일 2회) | 미반영 | 첫 체험 → 가입 게이트 |
| **공식 3이닝** | 3이닝 | 불가 | 반영 | 일일 메인 플레이 |
| **풀게임 9이닝** | 9이닝 (약 10분) | 불가 | 반영 | 헤비 유저 / 주말 |
| **오늘의 야구** | 1이닝 (날짜 테마) | 가능 1회 | 반영(회원) | 데일리 복귀 트리거 |
| **약점 코스 훈련** | 5타석 | 불가 | XP만 | 복습 |
| **고스트 대결** | 1이닝 | 응답은 가능 | 반영(회원) | 바이럴 |

### 4.4 라이트 유저 안전장치

야구 메타포는 핵심 자산이지만 비(非)야구팬에게는 진입 장벽이 될 수 있다.

- 첫 타석 전 설명 없음. 아웃 발생 시 상단에 `아웃 1 / 3`만 커지고, 안타 시 다이아몬드에 주자 점이 이동한다. 규칙은 유추로 전달한다.
- `자세히 보기` 토글로 판정표 전문 제공.
- 설정에서 **클래식 모드**(점수제 표기) 전환 제공, 내부 판정은 동일. 전환율·완주율 A/B 측정 대상.

## 5. 획기적 차별화 포인트

### D1. 박스스코어가 남는 퀴즈 — "통산 타율" 영구 기록

**정의.** 모든 플레이가 타석 원장(`at_bats`)에 기록되고, 개인에게 `타율 / 출루율 / 장타율 / OPS / 홈런 / 통산 타석`이 쌓인다. 결과 화면은 점수판이 아니라 **박스스코어**다.

**왜 획기적인가.** 퀴즈앱의 "총점 12,480점"은 아무 의미가 없지만, 야구팬에게 **`통산 타율 .327 / OPS .901`은 즉시 해석되는 신분증**이다. 숫자 하나로 자기소개가 되고, 비교·자랑·집착의 대상이 된다. 리더보드도 누적 볼륨(득점)과 비율 지표(OPS)를 분리해 "많이 한 사람"과 "잘하는 사람"을 따로 세운다.

**작동.** `AVG=H/AB`, `OBP=(H+BB)/PA`, `SLG=TB/AB`, `OPS=OBP+SLG`. 비율 지표 랭킹 노출 최소 조건 **통산 50타석**. 체험(비회원) 타석은 기록에 포함되지 않으며, 가입 시 게스트 세션 승계로 소급 반영한다(§7.3).

**MVP 포함.** 리스크: 지표 인플레이션 → 시즌 단위 리셋(통산은 영구 보존) 및 난이도 분포 고정으로 관리.

### D2. 상시 팬 페넌트레이스 — 내 1이닝이 구단의 오늘 승리가 된다

**정의.** 대표 구단을 선택한 회원의 **당일 공식 타석이 구단 단위로 집계**되고, 매일 두 구단이 맞붙어 **승·패**가 기록된다. 순위표는 승률·게임차로 표시되는 **페넌트레이스 표**다.

**왜 획기적인가.** 퀴즈앱 리텐션의 한계는 "내 기록"이 전부라는 점이다. 여기서는 **접속하지 않으면 팀이 진다.** KBO 팬덤의 소속감·라이벌 의식이 그대로 일일 활성 유저 동력으로 전환된다. 또한 전환 설계의 결정적 레버가 된다 — *"이 1이닝은 아직 어느 구단에도 반영되지 않았습니다."*

**작동.**

- 집계 지표: **팬덤 OPS**(절대 인구수가 아닌 비율 지표) → 팬 수가 적은 구단도 불리하지 않다.
- 일일 기여 상한: **1인당 그날의 첫 공식 3이닝만 집계.** 헤비 유저가 결과를 혼자 좌우하지 못하고, 넓은 참여가 유리해진다(= 팬덤이 서로를 호출하는 구조).
- 대진: 정규시즌 중에는 **실제 경기 일정과 동일한 대진**, 비시즌에는 자동 라운드로빈.
- 최소 참가 팬 수 미달(초기 10명, 안정화 후 30명) 시 **무효 경기(NC)** 로 기록하고 승률 계산에서 제외한다.
- 대표 구단은 **매일 00:00 기준 스냅샷**으로 고정. 팀 변경은 익일부터 적용되며 소급 이동 없다(V1 원칙 승계).
- 어뷰징 방지: 계정당 일일 기여 상한, 응답시간 분포 이상 탐지, 다계정 의심 시 기여 보류 후 운영자 검토. 집계는 원장 기반이라 **언제든 재계산 가능**하게 설계한다.

**MVP: 베타(비시즌 라운드로빈) → 2차 정식.** 리스크: 실제 경기 일정 데이터 확보(사실 정보지만 출처·갱신 책임 필요), 저트래픽 구간의 무효 경기 다발.

### D3. 스카우팅 리포트 + 스트라이크존 약점 맵

**정의.** 레벨 배지 대신 **20~80 스케일 5툴 스카우팅 리포트**를 발급한다. 약점은 **스트라이크존 9분할 히트맵**으로 보여주고, 그 칸에서 바로 출제한다.

| 툴 | 산출 근거 |
|---|---|
| 컨택 | 전체 정답률 |
| 파워 | 고급 난이도 정답률 |
| 주력 | 평균 응답시간 |
| 수비 | 야구 규칙·상식 정답률 |
| 송구 | 선수 기록·구단 역사 암기 정답률 |
| **종합(OFP)** | 가중 합산 |

**왜 획기적인가.** "Lv.4 / XP 3,500"은 게임 UI지만, **`컨택 60 / 파워 45 / 주력 70, 종합 55`는 야구 담화 그 자체**다. 공유 가치가 압도적으로 높고(스카우팅 리포트 카드), 약점이 구체적 행동으로 번역된다.

**존 맵.** 3×3 그리드 — **가로축 = 시대**(1982~1999 / 2000~2014 / 2015~현재), **세로축 = 난이도**(초급/중급/고급). 칸 색 = 정답률. 예: *"당신의 구멍은 몸쪽 높은 코스 — 1982~1999 고급 (정답률 23%)."* `[이 코스 집중 훈련]` 버튼이 해당 칸에서만 5타석을 출제한다.

**적응형 실력 추정.** V1의 20문제 선행 테스트를 폐지한다. 대신 문항 난이도 파라미터와 응답 결과로 **플레이 중 실력을 갱신**하고, 누적 **30타석** 시점에 "시범경기 종료 — 스카우팅 리포트 공개" 연출로 등급을 발급한다. 가입 장벽 제거와 개인화를 동시에 얻는다.

**MVP: 리포트·존 맵 수집 시작 + 2차 공개 연출.** 리스크: 표본 부족 구간의 과대 추정 → 지표별 최소 20타석 미달 시 `관찰중` 표기.

### D4. "그날의 야구" — 날짜가 콘텐츠를 생산한다

**정의.** 오늘 날짜(월/일)에 KBO 역사에서 벌어진 사건·기록을 템플릿으로 **자동 출제**한다. 10월 23일이면 역대 10월 23일의 한국시리즈·기록을 묻는다.

**왜 획기적인가.** V1의 5,000문제 수기 생산 계획은 운영 리스크 1순위다. 날짜 축으로 구조화된 기록을 두면 **365일치 콘텐츠가 매년 자동 순환**하고, "오늘"이라는 맥락이 복귀 사유가 된다. 공유 문구도 저절로 생긴다 — *"42년 전 오늘을 기억하십니까?"*

**작동.** 구조화 기록(날짜·구단·선수·수치) + 검증된 문항 템플릿 → 자동 초안 생성 → **운영자 승인 후에만 게시**(V1 검수 원칙 승계, 자동 생성물의 무검수 게시 금지). 기록 기준일은 문항에 반드시 표기한다.

**MVP: 수동 큐레이션 30일분 → 2차 자동 파이프라인.** 리스크: **데이터 사용권이 선행 조건.** 라이선스 확보 전에는 자체 작성 문항과 검증된 공개 사실만 사용한다.

---

### D5. 고스트 대결 — 동시접속 없는 1:1

**정의.** 내 1이닝을 **스냅샷**(문항 순서 + 타석별 결과 + 응답시간)으로 저장해 링크로 공유한다. 상대는 **같은 문항 순서**로 플레이하며, 화면에서 내 주자·득점이 **같은 경기장에서 동시에 진행되는 것처럼 재생**된다.

**왜 획기적인가.** V1 실시간 방은 2명 이상의 동시 접속을 요구한다. 초기 서비스에서 이는 "빈 대기실 → 이탈"로 직결된다. 고스트는 **링크 1개로 무제한 다수가 각자 편한 시간에** 도전하고, 보낸 사람은 결과 알림으로 되돌아온다. 메신저 단체방 1회 공유가 N명의 유입이 되는 구조이며, 구현 난도는 실시간 서버보다 현저히 낮다.

**작동.** 링크 만료 7일. 비회원도 **생성 1회·응답 무제한** 허용(바이럴 극대화). 단, **결과 알림 수신·재대결(복수전) 링크 생성·전적 기록은 회원 전용** → 자연스러운 게이트. 문항 시퀀스가 고정되므로 정답 유출 방지를 위해 **같은 링크에 대한 재응시는 전적 미반영**.

**MVP 포함.** 실시간 2~10인 방은 트래픽 확보 후 2차.

### D6. 라이브 세컨드스크린 (3차 · 조건부)

실제 경기 중 "다음 타석 결과 예측" 등 라이브 문항을 운영한다. 중계 시청과 동시 사용되는 세컨드스크린 포지션은 가장 강력한 차별화지만 **실시간 경기 데이터 라이선스 확보가 절대 선행 조건**이다. 미확보 시 전면 보류하며 MVP 범위에서 제외한다.

## 7. 즉시 플레이 → 가입 전환 설계

### 7.1 퍼널

```text
랜딩(= 1번 타석)  →  타석 1 제출  →  1이닝 완주  →  박스스코어
     0탭              3초 내          60~90초          ↓
                                              [게이트 G1~G3]
                                                    ↓
                              소셜 1탭 가입  →  구단 1개 선택  →  대시보드
                                                    ↓
                                          게스트 세션 승계(기록 소급)
```

### 7.2 가입 게이트 3종 — 모두 "플레이 이후"에만 작동

| ID | 시점 | 노출 | 문구(초안) |
|---|---|---|---|
| **G1** 기록 저장 | 1이닝 종료 직후 | 박스스코어는 전부 공개. 스카우팅 리포트는 **2개 툴만 공개, 나머지 블러** | "이 타석들은 아직 저장되지 않았습니다. 통산 타율에 적립하고 리포트를 받으려면 — 3초 가입" |
| **G2** 구단 기여 | 결과 화면 하단 | 오늘의 팬 페넌트레이스 대진표 + 내 기여 `0 PA` | "이 1이닝은 아직 어느 구단에도 반영되지 않았습니다. 구단을 고르면 오늘 경기에 집계됩니다" |
| **G3** 대결 전적 | 고스트 결과 화면 | 승패는 보여주되 전적은 `-` | "복수전 링크를 만들고 상대 전적을 남기려면 회원이어야 합니다" |

추가 상한: **비회원은 1일 2이닝**(서버 집계 게스트 세션 기준). 초과 안내는 사후가 아니라 **시작 전에 명시**한다 — "오늘 체험 1이닝이 남았습니다."

단계별 게이트 구성: **P1에서는 G1을 "통산 타율 적립"만으로 운영**한다(스카우팅 리포트는 P2에서 공개되므로 블러 연출도 P2부터). G2는 팬 페넌트레이스 베타(P2)와 함께, G3는 고스트 대결(P2)과 함께 켠다. 즉 P1 출시 시점의 전환 레버는 **G1 단독**이며, 이것만으로 목표 전환율 25%를 검증한 뒤 레버를 추가한다.

### 7.3 게스트 → 회원 무손실 승계 (필수 요건)

- 첫 방문 시 서버가 `guest_session`을 생성하고 토큰을 **httpOnly 쿠키**로 내린다(클라이언트 점수 신뢰 금지, V1 원칙 승계).
- 가입 완료 직후 `POST /auth/claim-guest`가 해당 게스트 세션의 타석·박스스코어를 회원 계정으로 이관한다. **멱등 처리**(동일 토큰 2회 호출 시 중복 적립 없음).
- 승계 후 즉시 보여줄 것: "방금 기록이 통산에 적립되었습니다 — 2타수 1안타, 타율 .500". **가입의 보상을 1초 안에 체감**시킨다.
- OAuth 리다이렉트 왕복 중에도 게스트 토큰과 원래 초대·고스트 링크를 보존한다(V1 UX 예외 흐름 승계).

### 7.4 가입 자체를 3초로

| 단계 | V1 | V2 |
|---|---|---|
| 1 | 소셜/이메일 선택 | 소셜 1탭 (이메일은 접힌 보조 옵션) |
| 2 | 닉네임 입력(2~16자, 중복 확인) | 닉네임 **자동 추천**(수정 가능, 중복 즉시 회피) |
| 3 | 최애 구단 TOP3 (1위 필수) | **대표 구단 1개만** (페넌트레이스 참가 필수 사유 명시) |
| 4 | 최애 선수 TOP3 | 제거 → 설정에서 선택 |
| 5 | **20문제 레벨 테스트** | **폐지** → 플레이 중 적응형 추정 |

약관·개인정보 동의는 분리 체크로 유지하되 **가입 버튼 지점에 1줄 + 링크**로 배치한다. 미성년자 처리 정책은 V1 보류 항목이므로 법적 검토 전 확정하지 않는다.

### 7.5 금지 사항 (다크패턴 차단)

첫 화면 가입 모달 / 1문제 후 강제 가입 / 결과를 보기 위한 가입 강제(박스스코어는 비회원도 전부 본다) / 가짜 긴급 카운트다운 / 불필요한 권한·연락처 요구 / 이메일 인증 완료 전 플레이 차단 / 탈퇴·데이터 삭제 경로 은폐.

### 7.6 목표 퍼널 (가설 — 실측값 아님)

| 지표 | 목표 |
|---|---|
| 랜딩 → 첫 타석 제출 | 70% |
| 첫 타석 → 1이닝 완주 | 75% |
| 결과 화면 → 가입 시작 | 25% |
| 가입 시작 → 구단 선택 완료 | 92% |
| 가입 → 당일 공식 1이닝 | 80% |
| D1 / D7 / D30 재방문 | 35% / 20% / 10% |
| 공유 카드 생성률(결과 기준) | 12% |
| 고스트 링크 1건당 신규 유입 | 0.35명 |

북극성 지표는 V1을 계승·구체화한다 → **주간 공식 타석 30회 이상 완료 회원 수**(WAU 중 실질 플레이어).

## 8. 반응형 설계 — 모바일 / 태블릿 / PC

### 8.1 브레이크포인트

| 이름 | 범위 | 기준 디바이스 |
|---|---|---|
| `sm` 모바일 | 360 ~ 599px | 한 손 조작, 세로 |
| `md` 태블릿 | 600 ~ 1023px | 세로·가로 양방향 |
| `lg` 데스크톱 | 1024 ~ 1439px | 마우스 + 키보드 |
| `xl` 와이드 | 1440px+ | 중앙 정렬, 최대 폭 1320px |

### 8.2 경기 화면 레이아웃 (`/play`)

**sm — 1열 수직, 엄지 우선**

```text
┌──────────────────────────────┐
│ 이닝 1 ▲  아웃 ●●○   R 2     │ ← 고정 헤더 56px (스코어보드)
│      ◇ 주자 다이아몬드        │ ← 72px
├──────────────────────────────┤
│                              │
│        문제 카드              │ ← 가변, 최소 폰트 17px
│   (카테고리·난이도·기준일)     │
│                              │
├──────────────────────────────┤
│  ⏱ ▓▓▓▓▓▓░░░  8.2s          │
├───────────────┬──────────────┤
│   A 보기      │   B 보기      │ ← 2×2 그리드
│   C 보기      │   D 보기      │   각 높이 ≥ 56px
└───────────────┴──────────────┘
         하단 탭바는 경기 중 숨김
```

**md — 2열**: 좌 40%에 스코어보드·다이아몬드·타석 로그(중계 티커), 우 60%에 문제 + 보기 2×2. 가로모드에서는 보기를 1×4 하단 바로 재배치해 시선 이동을 줄인다.

**lg/xl — 3열**: 좌 사이드바(네비·내 등급·오늘 기여), 중앙 경기(최대 폭 720px, 보기 2×2), 우 패널(**오늘의 팬 페넌트레이스 라이브 / 고스트 상대 진행 상황 / 타석 로그**). V1에 없던 우측 패널이 PC의 넓은 화면을 실제 정보 가치로 채운다.

### 8.3 입력 체계

| 환경 | 조작 |
|---|---|
| 터치 | 보기 탭. 주 버튼 56px, 보조 44px. 하단 1/3(엄지 존)에 보기 배치. `safe-area-inset-bottom` 반영 |
| 키보드 | `1~4` 또는 `A/S/D/F`로 보기 선택, `Enter` 다음 타석, `Esc` 일시정지 확인. 선택 후 0.4초 내 재입력 무시(오입력 방지) |
| 마우스 | hover 프리뷰 + 클릭. 드래그 불필요 |
| 스크린리더 | 타석 상태를 `aria-live="polite"`로 고지("아웃 2, 주자 1루, 득점 2") |

### 8.4 공통 요건 (V1 승계 + 강화)

- 360px에서 가로 스크롤 0, 다크모드 기본 지원, WCAG 2.2 AA 지향.
- 정답/오답을 **색만으로 표현 금지** — 아이콘 + 텍스트 병기(`안타`, `아웃`).
- `prefers-reduced-motion` 시 주자 이동 애니메이션을 즉시 상태 전환으로 대체.
- 타이머는 숫자 + 진행 바 동시 표기. **화면 타이머와 무관하게 서버 판정이 최종**(V1 원칙).
- 성능 **목표**(실측 아님): LCP 2.5s, 일반 API p95 500ms, 타석 제출 p95 300ms.
- 공유 카드(OG 이미지)는 1200×630 고정 생성, 노출 정보는 **닉네임·등급·박스스코어로 제한**.

## 9. 경제·성장 재설계

- **경기 지표**: 득점(R)이 경기 승패를 가른다. 내부 점수 환산값은 UI에 노출하지 않는다.
- **랭킹 분리**: ① 비율 — 통산 OPS(최소 50타석) ② 볼륨 — 시즌 누적 득점 ③ 집단 — 팬 페넌트레이스 승률·게임차. 동점 규칙은 V1 계승(정답률 → 평균 응답시간 → 선착).
- **XP·레벨**: 임계값은 V1 유지(`0/500/1500/3500/7000/12000/20000`)해 마이그레이션 부담을 없애고, **표기만 야구 등급**으로 교체 — `육성선수 / 백업 / 주전 / 올스타 / 골든글러브 / MVP / 명예의 전당`.
- **XP 이벤트**: V1 표를 승계하되 세션 단위를 이닝 단위로 환산(`inning_complete` 일 5회, `daily_complete` 일 1회, `ghost_win` 일 5회, `zone_training_complete` 일 2회, `streak_7d`). 멱등 키 `eventType:entityId:userId` 유지.
- **배치 XP**: 적응형 추정으로 등급 발급 시 `placement_grant` 1회 지급(V1 규칙 승계, 원장 중복 차단).
- **RP/Elo**: V1대로 2차. 고스트·친선 대결은 RP 미지급.
