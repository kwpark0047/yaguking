# 야구왕 (YaguKing) — 통합 제품 요구사항 PRD

> **Firebase 무료판 안내(2026-10-26)** — 이 문서의 플랫폼 부분(Supabase·Vercel·서버 판정 등)은 16 문서(무료 플랜 Firebase 전환) §4의 "01" 줄로 바뀌었다. 본문은 그대로 둔다.

- 버전: 1.0 / 기준일: 2026-10-23
- 상태: 개발 착수용 기획 기준안. **구현·배포·실제 KBO 데이터 사용권 확보 전**
- 목표: KBO 1982년 이후 기록을 활용한 4지선다 퀴즈, 친구 실시간 대결, 성장·복습·팬 랭킹 플랫폼
- 기술: Next.js App Router / TypeScript / Tailwind / shadcn/ui / Supabase Auth·Postgres·Realtime / 서버 권한 게임 엔진

## 1. 제품 목표 및 성공 지표

핵심 가치: (1) 검증된 KBO 기록 퀴즈 (2) 링크 하나로 친구 대결 (3) 최애 구단·선수 기반 개인화 (4) 오답 복습과 레벨 성장.

90일 **가설 목표**: 방문 30,000명, 누적 플레이어 10,000명, D7 재방문율 25%, 초대 유입 비중 40%. 실제 수요 예측치가 아니며 실험으로 검증한다.

북극성 지표: 주간 **유효 게임 완료 회원 수**(공식 개인/친구/데일리 게임을 정상 종료한 고유 회원). 보조 지표: 방문→첫 게임 시작, 첫 게임 완료, 가입, 레벨테스트 완료, 초대 공유→유입→게임 완료, D1/D7/D30 유지율, 오답 복습률, 구단별 참여율, 신고율.

## 2. 역할 및 접근 정책

| 유형 | 기능 | 제한 |
|---|---|---|
| 비회원 | 3~5문제 체험, 공개 콘텐츠, 초대 링크 열람 | 공식 XP/RP 없음; 임시 세션; 비공식 방 참가 여부는 운영 설정 |
| 회원(테스트 전) | 온보딩, 개인 연습, 선호 설정 | 공식 경쟁 랭킹 제외 |
| 정식 회원 | 공식 개인·데일리·친구 게임, 개인 통계, 오답노트, 팬 랭킹 | 서버 규칙 준수 |
| 방장 | 방 설정·시작·참가 관리 | 방장 권한은 서버 확인 |

**로그인 전략**: 비회원 즉시 플레이 유지. 회원가입 후 닉네임·선호 구단/선수 설정 및 최초 레벨 테스트로 연결. 회원가입 직후 모든 콘텐츠를 강제로 차단하지 않고 테스트 미완료 상태에서 연습 허용.

## 3. 주요 사용자 흐름

1. 신규 방문: 홈 → 비회원 3문제 → 결과·공유 → 가입 유도.
2. 가입: Auth → 닉네임 → 최애 구단 TOP3(1위 필수) → 최애 선수 TOP3(선택) → 20문제 최초 레벨 테스트 → 등급 인증 카드 → 대시보드.
3. 개인 게임: 카테고리·난이도 선택 → 10문제 풀이 → 점수·해설 → 오답 자동 기록 → 추천 복습.
4. 친구 대결: 방 생성 → 코드/링크 공유 → 2~10명 준비 → 동일 문항·동일 마감시간 → 결과 → 재대결·공유.
5. 성장: XP 획득 → 자동 승급 또는 승급시험 → 배지 → 약점 보완 → 재방문.
6. 팬 경쟁: 대표 응원팀 선택 → 유효 점수 반영 → 구단별 평균/활성 참가자 랭킹. 이벤트 중 팀 변경으로 점수 이동 불가.

## 5. 퀴즈 콘텐츠 및 운영

카테고리: KBO 역사, 선수 기록, 구단 역사, 한국시리즈, 야구 규칙·상식. 최초 레벨 테스트는 각 4문제. 문제 난이도 초급 8/중급 8/고급 4. 시즌·통산·기록 기준일을 반드시 문제에 명시하여 정답 변경을 방지한다. 정답은 정확히 하나. 문항당 출처 URL/원천/검증일/승인자/버전 보관.

초기 검수 완료 500문제로 비공개 베타 시작; 5,000문제는 확장 목표. 공식 KBO 기록실 https://www.koreabaseball.com/Record/Main.aspx 참조. **상업적 데이터 사용권, 로고·선수 사진·상표 이용 가능 범위를 법적 검토 전 확정하지 않는다.** 무단 대량 수집이나 비허가 이미지 재사용 금지.

## 6. 게임 경제 및 경쟁 정책

- 경기 점수: 정답 100 + floor(50 × (15−t)/15), t는 서버가 검증한 0~15초. 오답/시간초과 0.
- 연속 정답: 3연속 달성 +30, 5연속 및 이후 매 5연속 달성 +70. 오답·시간초과 시 0으로 초기화.
- XP: 정답 +10, 고급 최초 정답 추가 +5, 개인 게임 완료 +20(일 5회), 데일리 완료 +30(일 1회), 친구 게임 완료 +20(일 5회), 친구 게임 승리 추가 +30(일 5회), 오답 5개 복습 +20(일 2회), 7일 연속 +100(7일 주기 1회). 중복·악용 방지 정책 적용.
- 레벨: Lv1 0, Lv2 500, Lv3 1500, Lv4 3500, Lv5 7000, Lv6 12000, Lv7 20000 XP. 최초 테스트 배정 레벨의 최소 XP를 `placement_grant`로 지급.
- 최초 테스트 정답 수: 0~5→Lv1, 6~9→Lv2, 10~13→Lv3, 14~17→Lv4, 18~20→Lv5.
- 승급 시험(2차): Lv4·5는 10문제 70%, Lv6·7은 20문제 80%, 실패 시 24시간 재도전. MVP에서는 초기 테스트로 Lv4·5 배정 가능, 일반 XP 자동 승급은 Lv3까지.
- RP: **MVP 친구 대결은 RP 미지급**. 2차 공식 1:1 랭크전에서 초기 1000, Elo K=32(첫 20전)/16(이후), 승 1/무 0.5/패 0.
- 리더보드: 개인 시즌 총점(공식 게임 한정), 최고점, 승률 등 별도 지표. RP 랭킹은 2차. 구단 랭킹은 이벤트 기간 고유 참가자별 평균 유효 점수 및 최소 참가자 수 조건 적용.

## 7. 데이터·보안·비기능 요건

모든 공식 정답·점수·시간은 서버 판정. 답안은 최초 1회만 인정. 서버가 정답 공개 전에는 정답 컬럼을 제공하지 않는다. JWT의 수정 가능한 user_metadata로 권한 판정 금지. RLS는 모든 노출 스키마 테이블에 적용. 서버 키는 브라우저 노출 금지. 공개 프로필과 비공개 기록 분리. 로그에는 인증 토큰과 민감 개인정보 기록 금지.

목표: 모바일 360px 이상, WCAG 2.2 AA 지향, LCP 2.5초, 일반 API p95 500ms, 답안 p95 300ms, 서버 처리 후 이벤트 p95 500ms. **모두 성능 목표이며 실제 측정값이 아님.** 초기 100개 동시 대결방 부하 테스트. 스테이징·운영 분리, 백업 및 복구 리허설.
