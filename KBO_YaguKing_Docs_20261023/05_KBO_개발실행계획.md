## 1. 문서 검토 → 코드 구현 단계

**단계 0 — 환경 조사(읽기 전용)**
- `pwd`, `git status`, `node -v`, `npm -v`, `supabase --version`(설치된 경우), 프로젝트 파일·기존 Supabase/Vercel 참조 확인.
- 기존 프로젝트가 있으면 브랜치·미커밋 변경·환경변수 파일 목록을 파악하되 비밀값을 출력하지 않는다.
- 기존 DB를 새 프로젝트로 오인해 덮어쓰지 않는다. 신규 프로젝트인지 기존 프로젝트 통합인지 먼저 확정한다.

**단계 1 — 프로젝트 골격**
- Next.js App Router + TypeScript + Tailwind + shadcn/ui 초기화.
- `src/app`, `src/components`, `src/lib`, `src/server`, `supabase/migrations`, `tests` 구성.
- ESLint, Prettier, Vitest, Playwright, 타입체크 및 CI 기본 구성.

**단계 2 — Supabase 로컬/스테이징 DB**
- 공식 changelog·문서와 CLI 도움말 확인.
- `supabase migration new init_kbo_schema`로 파일 생성.
- 참조 데이터→회원→문제→게임→XP/랭킹→오답·운영 순서로 스키마 구현.
- RLS, 정답 비공개 스키마, 권한 GRANT/REVOKE, 인덱스·유일성 제약 구현.
- 다른 회원의 비공개 데이터 조회/수정 불가, 정답 유출 불가 테스트.

**단계 3 — Auth·온보딩**
- 구글/카카오/이메일 로그인(실제 활성화 공급자에 한함).
- 닉네임, 최애 구단 TOP3, 최애 선수 TOP3, 선수 자동완성, 프로필 저장.
- OAuth 리다이렉트/세션 갱신/초대 링크 복귀 테스트.

**단계 4 — 문제은행·검수**
- 문제/선택지/출처/검증일/버전/승인 상태 관리.
- 게시 시 보기 4개·정답 1개·출처 확인.
- 라이선스 검토 전에는 임의의 공개 기록과 자체 작성 테스트 문제만 사용.

**단계 5 — 최초 레벨 테스트·성장**
- 5영역×4문제, 난이도 8/8/4, 15초 제한.
- 진행 상태 복원, 최초 완료 1회, 정답 수에 따른 Lv1~5 배정.
- XP 원장 `placement_grant`와 총 XP 원자 갱신.
- 일반 XP 및 Lv1~3 자동 승급 구현.

**단계 6 — 개인 게임·오답노트**
- 서버 정답 판정·시간·연속 보너스, 결과·출처·오답 자동 기록.
- 복습 1/3/7/14일, 숙달 2회 정답, XP 중복 지급 방지.
- 데일리 5문제, 개인 통계/점수.

**단계 7 — 실시간 친구 대결**
- 방 생성/코드/준비/방장/2~10명.
- `WAITING→COUNTDOWN→QUESTION_ACTIVE→REVEAL→FINISHED`.
- Supabase Realtime으로 이벤트 방송, 서버 권한 게임 엔진으로 답안/시간/점수 판정.
- 재접속·중복 제출·방장 이탈·마감 경합 테스트.

**단계 8 — 랭킹·초대·운영**
- 개인/구단 랭킹, 친구 도전장·공유 카드, 초대 유입 이벤트, 운영자 검수 화면.
- 이벤트 중 대표 구단 스냅샷, 친선전 RP 미지급 확인.

**단계 9 — 보안·성능·출시 준비**
- 단위/통합/E2E/부하 테스트, RLS 보안 검토, 개인정보/데이터 이용권 확인.
- 스테이징 배포, DB 백업·복구·롤백 리허설, 승인 후 운영 배포.
