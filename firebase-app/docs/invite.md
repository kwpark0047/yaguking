# 친구 초대 1단계

> 상태: **구현(2026-11-18), 시행 2026-12-01**. 기획: Claude 문서 "야구왕 친구 초대·팀 플레이 기획"(운영자 결정 2026-11-18).
> 2단계(팀·팀 로고)·3단계(팀 플레이)·4단계(시즌)는 이 단계가 자리 잡은 뒤 같은 방식으로 연다.

## 저장

| 위치 | 쓰는 쪽 |
|---|---|
| `invites/{코드}` {uid, createdAt} | 본인(내 프로필 `inviteCode`와 한 묶음, 한 번) |
| `users/{uid}`의 `inviteCode`·`invitedBy`·`invitedAt` | 본인 — 규칙: 받은 코드는 닉네임 뒤, 가입 후 7일 안, 남의 코드, 한 번, 서버 시각 |
| `inviteLedger/{초대받은 uid}` | 운영자 PC만. 초대한 사람·받은 사람이 읽는다 |
| `users/{uid}/meta/invites` {bonus, rewarded, titles} | 운영자 PC만(진행 기록 전체에서 매일 다시 계산) |

## 운영

- 0시 작업 순서: `invites` → `wallet` (`ops/run-cleanup.cmd`). 시행일 전에는 아무것도 하지 않는다
- 부정으로 본 초대 보상 취소: `node ops/admin-cli.mjs invite-revoke --project=yaguking-bc25c --uid=<초대받은 회원 uid>` — 관리자 기록을 남기고, 다음 0시에 합계·지갑이 다시 계산된다
- 처리방침 개정판(시행 12-01)은 앱이 7일 전부터 개정 예고를 자동으로 띄운다. 공지사항에도 올린다(11-24까지)
- 미니앱판: 운영자 결정에 따라 앱인토스 자체 초대 보상 제도를 쓴다 — 웹판 초대는 미니앱에 넣지 않았다(`main.tsx`에만 `captureInvite`)

## 검증

- 단위: 앱·운영자 PC·규칙·처리방침 값 일치, 코드·링크·활동 확인·합계 순수 함수
- 규칙(에뮬레이터): 코드 한 번·남의 uid 금지·형식, 받은 코드 7일·한 번·자기 코드 금지·서버 시각, 진행 기록 읽기 범위
- 운영(에뮬레이터): 연결→확인 중→보상(이벤트 2배)·다시 돌려도 같음, 오늘 경기 제외·기간 지남, 월 10명 상한·칭호, 지갑 합산, 취소·탈퇴 정리
- E2E: 내 코드·현황, 링크로 가입하면 자동 연결(주소창에서 코드 지움), 직접 넣기 오류 안내, 비회원 안내
