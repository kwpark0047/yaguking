구체화한 문서다.

**승인·구현(2026-10-28)** — 권장안대로(기본 끔, 버튼 소리 따로 기본 끔, §2 전부). `src/lib/sound/sound.ts`(설정·합성·소리 표 한 파일,
첫 누름에 장치 켬, 무음 스위치 존중, 동시 3개·0.1초 중복 막음), 홈·설정의 "소리"(끄기·작게·보통·크게), 설정의 "버튼 누를 때 소리",
경기 화면 머리줄의 소리 단추, 처리방침 §10에 `yk_sound`. 대결 카운트다운 소리는 카운트다운(효과 2차)과 함께 — 아직 없음.
확인: 단위(기본값·저장·판정→소리·종료 단계), E2E(기본 끔이면 소리 장치가 생기지 않음, 켜면 생김·기기에 남음·단추로 끔).
실제 소리의 크기·거슬림은 사람 귀로 확인할 것.

## 1. 원칙

1. **소리 파일을 쓰지 않는다.** 브라우저의 소리 합성(Web Audio)으로 그 자리에서 만든다 — 받을 파일 0 KB(무료 전송량 그대로),
   녹음·음원 저작권 문제 없음. 합성 코드는 효과 엔진처럼 **처음 소리가 필요할 때** 따로 받는다(약 3 KB)
2. **기본은 끔.** 설정 "소리"를 켠 사람만 듣는다(공공장소·수업 중에 갑자기 울리지 않게). 첫 화면에 "소리 켜기" 안내를 한 번만
3. **짧고 작게.** 효과음은 0.1~1.2초, 음량 기본 "보통"(최대치의 약 60%), 동시에 3개 넘게 겹치지 않음, 모든 소리를 압축기
   (DynamicsCompressor)에 통과시켜 갑자기 커지지 않게
4. **소리만으로 알리지 않는다.** 모든 소리에는 같은 뜻의 글자·화면 표시가 이미 있다(접근성). 배경 음악은 넣지 않는다
5. **휴대폰 무음 모드 존중.** 지원하는 브라우저(iOS 17+ Safari 등)는 `navigator.audioSession.type = 'ambient'` — 무음 스위치를 따르고
   다른 앱 음악을 끊지 않는다. 브라우저가 막는 자동 재생은 시도하지 않는다(첫 터치 뒤에만 소리 장치를 켠다)

## 3. 설정

| 설정 | 값 | 기본 |
|---|---|---|
| 소리 | 켜기 · **끄기** | 끄기 |
| 음량 | 작게 · **보통** · 크게 | 보통 |
| 버튼 소리 | 켜기 · **끄기** | 끄기 |

- 홈(누구나)과 설정 화면(회원)에 "화면 효과" 옆에 둔다. 경기 화면 머리줄에 소리 켜고 끄는 작은 단추(🔈/🔇 모양 SVG)
- **기기에만 저장**(`yk_sound` 하나에 JSON). 기기 저장 키가 늘어나므로 **처리방침 §10 표에 추가**(개인정보 아님 — 화면 효과
  설정과 같은 방식, 단위 테스트가 키 목록을 대조)
- 서버 읽기·쓰기 0

## 4. 기술

- `src/lib/sound/`: 설정(preference), 소리 표(catalog), 입구 `playSound('homeRun')`, 엔진(합성 — 필요할 때 받음)
- 소리 장치(AudioContext)는 **소리가 켜져 있고 사용자가 한 번 누른 뒤**에만 만든다. 탭이 가려지면 멈춘다(`suspend`)
- 축하 효과와 같은 순간에 부르도록 `celebrate()`에 소리 이름을 함께 둔다(효과 단계 none이어도 소리 설정은 따로)
- 동시 재생 상한 3, 같은 소리 0.1초 안에 다시 부르면 무시

## 5. 확인

- 단위: 순간 → 소리 고르기, 설정 기본값·저장, 음량 계산
- E2E: 소리 끔(기본)이면 AudioContext가 생기지 않음, 켜면 첫 누름 뒤에만 생김(브라우저 정책), 설정이 기기에 남음, 처리방침 표에 키
- 사람 귀 확인: 휴대폰 스피커·이어폰에서 음량·거슬림(운영자). 소리 파형은 테스트로 검증하기 어렵다

## 6. 정해 주실 것

1. 기본값 — **끔(권장)** / 켬
2. 버튼 소리 — **따로 두고 기본 끔(권장)** / 없음
3. 범위 — **§2 전부 한 번에(권장, 합성이라 추가 파일 없음)** / 경기 소리만 먼저
