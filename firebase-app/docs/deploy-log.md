## 2026-10-26 — 2차 배포: 없는 파일은 404

- 문제: 화면 주소 처리(`"source": "**"`)가 없는 `/assets/x.js`까지 `index.html`(200)로 돌려주고, `/assets/**`의 1년 캐시까지 붙었다
- 고침: `"source": "**/!(*.*)"` — 마지막 조각에 점이 없는 주소(화면 주소)만 `index.html`. 화면 주소에는 점이 없다(단위 테스트가 지킴)
- 정규식(`"regex": "^/[^.]*$"`)은 Hosting 에뮬레이터에서 화면 주소까지 404가 나서 쓰지 않았다(확인할 수 없는 설정은 올리지 않음)
- 확인: 에뮬레이터에서 화면 주소 200·없는 파일 404 → 미리보기 → 실제 사이트(배포 메시지 "cd9d89b assets 404")
- 실제 사이트 결과: `/`·`/play`·`/room/ABC234`·`/notes`·`/settings` 200(HTML), 있는 묶음 파일 200,
  `/assets/does-not-exist.js`·`/nope.txt` **404**. `/play`를 바로 열어도 첫 문제까지 뜨고 콘솔 메시지 0
