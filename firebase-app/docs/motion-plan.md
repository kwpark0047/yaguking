# 애니메이션 2차 기획 — 화면 전환·가입·첫 안타·첫 홈런·아웃·랭킹 (기획만 — 승인 뒤 구현)

2026-10-28. 축하 효과 1차(`docs/effects-plan.md`, 운영 중)에 **심플한** 움직임을 더한다. 같은 원칙을 따른다:
짧게(0.2~1.2초), 누르는 것을 막지 않게, 설정 "화면 효과"(켜기·줄이기·끄기)와 기기의 동작 줄이기를 따름, 결과는 글자로 먼저.
새 라이브러리 없음(CSS + 이미 있는 효과 엔진). **아직 만들지 않았다.**

## 1. 화면 전환

| 언제 | 움직임 | 길이 |
|---|---|---|
| 앱 안 화면 이동(홈 ↔ 경기·오답노트·대결·설정 등) | 이전 화면은 살짝 흐려지고, 새 화면이 아래에서 8px 올라오며 나타남 | 0.2초 |
| 뒤로 가기 | 같은 움직임을 반대로(위에서 내려옴) | 0.2초 |
| 경기 안 "다음 타석" | 문제 카드가 옆으로 밀려 들어옴(투구 느낌) | 0.25초 |

- 브라우저의 **View Transitions**(React Router의 `viewTransition`)로. 지원하지 않는 브라우저는 그냥 바로 바뀜(지금과 같음)
- "줄이기"는 흐려지기만(이동 없음), "끄기"·동작 줄이기는 없음
- 화면 읽기: 새 화면 제목으로 초점 이동은 지금처럼(움직임과 무관)

## 3. 첫 안타·첫 홈런

"첫"의 기준을 정해야 한다(§7-2):

| 기준 | 장점 | 비용 |
|---|---|---|
| **이번 경기의 첫 안타·첫 홈런**(권장) | 매 경기 작은 즐거움, 읽기 0 | 없음 |
| 생애 첫 안타·첫 홈런 | 특별함 | 회원은 누적 기록을 경기 전에 읽어야 함(읽기 1), 비회원은 기기에 저장(처리방침 기기 저장 항목 추가) |

움직임(이번 경기 기준):

| 순간 | 움직임 |
|---|---|
| 첫 안타 | 판정 글자 옆에 "첫 안타!" 작은 배지가 톡 튀어나옴 + 전광판의 1루 주자 자리가 반짝 + 주자 아이콘이 홈→1루로 미끄러짐 |
| 첫 홈런 | 지금의 홈런 폭죽에 **"첫 홈런!" 도장**이 쾅 찍힘(0.4초). 두 번째 홈런부터는 도장 없이 폭죽만(한 판 큰 효과 3번 상한 그대로) |
| 첫 장타(2·3루타) | 별도 없음(안타와 같은 배지 규칙 — "첫 안타"에 포함) |

## 5. 랭킹 등록·랭킹 승급

**지금 앱에는 랭킹이 없다.** 공식 랭킹은 설계만 있고(`docs/official-xp-rp.md` — 기기 채점 점수는 공식 랭킹에 넣지 않는 원칙),
비공식 점수로 순위표를 만들면 조작된 점수가 1등이 된다. 그래서 둘 중 고른다(§7-3):

| 안 | "랭킹 등록" 연출 | "랭킹 승급" 연출 | 비고 |
|---|---|---|---|
| **A. 지금 있는 것에 연결(권장)** | **친구 대결 최종 순위 발표**: 순위 카드가 3위부터 차례로 올라오고(0.2초 간격) 내 순위 카드가 강조, 1등은 왕관이 떨어져 앉음 | **비공식 레벨 승급**(누적 비공식 XP로 육성선수 → 백업 → 주전 …): 경기 결과에서 진행 막대가 차오르다 넘치면 "승급! 백업 → 주전" 카드 두 장이 밀려나고 들어옴 + 등급색 폭죽 | 레벨은 경기 끝에 누적 기록을 1번 읽어 계산(읽기 +1/판). 화면에 "비공식" 표시 |
| B. 공식 랭킹이 생긴 뒤 | 공식 랭킹에 처음 오를 때 "랭킹 등록!" 띠 + 순위 숫자 롤링 | 순위가 오를 때 "▲3" 숫자가 위로 튀며 이전 → 새 순위 | 공식전(7단계 설계) 승인·구현이 먼저 |

A로 만들면 공식 랭킹이 생겼을 때 같은 부품(순위 카드·승급 카드)을 그대로 쓴다.

## 6. 만드는 방법·확인

- 부품: CSS 키프레임(띠·배지·도장·흔들림·순위 카드) + 이미 있는 효과 엔진(꽃가루·폭죽) + View Transitions. 새 파일은 CSS 수십 줄과
  작은 컴포넌트 몇 개. 첫 화면 크기 변화 1 KB 안
- 효과 표(`src/lib/effects/catalog.ts`)에 새 순간(firstHit·firstHomeRun·out·inningEnd·welcome·rankReveal·levelUp)을 더해 강도·상한을 한 곳에서
- 소리 기획(`docs/sound-plan.md`)을 함께 승인하면 같은 순간에 소리를 붙인다
- 확인: 단위(첫 안타·첫 홈런 판정, 레벨 계산, 강도), E2E(배지·도장·띠가 뜨고 사라짐, 효과 중에도 버튼이 눌림, 끄기·동작 줄이기에서
  움직임 없음, axe), 화면 캡처(밝은·어두운·폰·큰 화면)

## 7. 정해 주실 것

1. 화면 전환 — **넣기(권장, 0.2초)** / 빼기
2. "첫" 기준 — **이번 경기(권장)** / 생애 첫
3. 랭킹 — **A. 친구 대결 순위 발표 + 비공식 레벨 승급(권장)** / B. 공식 랭킹 뒤로 미룸
4. 레벨 승급 계산 때 경기 끝 읽기 +1 — **괜찮음(권장, 하루 한도에 미미)** / 읽지 않고 승급 연출 빼기
