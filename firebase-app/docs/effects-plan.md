## 1. 원칙

1. **짧게, 막지 않게.** 효과는 대부분 1.5초 안에 끝나고, 아무리 길어도 3초. 효과가 도는 동안에도 다음 버튼을 바로 누를 수
   있다(효과 층은 `pointer-events: none`, 초점을 옮기지 않는다)
2. **크기는 일의 크기만큼.** 매 타석 폭죽이 터지면 홈런이 특별하지 않다. 강도를 세 단계(작음·중간·큼, §3)로 나누고 큰 효과는
   한 판에 몇 번만(§5)
3. **움직임을 싫어하는 사람을 먼저.** 기기의 "동작 줄이기", 앱 설정 "화면 효과", 고대비 화면에서 입자·흔들림·번쩍임을 끄고
   **색·글자로만** 알린다(§6). 1초에 3번 넘게 번쩍이지 않는다
4. **결과는 글자로 먼저.** 화면 읽기 프로그램은 지금처럼 "홈런!", "Lv.3 주전" 같은 글자를 읽는다. 효과는 그 글자를 꾸밀 뿐이다
5. **무료·가볍게.** 외부 그림·소리·유료 라이브러리를 쓰지 않는다. 폭죽은 직접 만든 작은 캔버스 엔진(압축 약 3 KB)을 **처음
   필요할 때** 불러온다 — 첫 화면 크기는 그대로. Firestore 읽기·쓰기는 하나도 늘지 않는다(효과는 기기 안에서만)
6. **비공식임을 가리지 않는다.** 점수·등급 옆 "비공식" 표기는 효과 위에도 그대로 보인다

### 2-6. 승급(레벨업) — 공식 XP를 켠 뒤

지금 레벨(XP)은 7단계 설계만 있고 켜지 않았다(`docs/official-xp-rp.md`). 켜면 이렇게 한다:

- **승급 휘장 화면**: 결과 화면 위에 반투명 막, 가운데 "승급!" + **이전 등급 → 새 등급** 두 장의 카드가 밀려나고 들어옴,
  새 등급색 폭죽 3발. "확인"을 눌러야 닫힌다(유일하게 닫기 버튼이 있는 효과 — 그래서 초점은 "확인"으로 옮기고 Esc로도 닫힘)
- 진행 막대(`levelProgress`)가 차오르다 넘치면 휘장이 뜬다
- 비공식 기록으로는 승급 효과를 내지 않는다(공식 점수만 — 계획 원칙과 같음)

## 3. 효과 부품(만들 것)

이벤트마다 따로 만들지 않고 아래 부품을 조합한다. 색은 **보는 사람의 구단 강조색(`--accent`) + 금색 + 흰색**, 등급 효과는
등급색(`--tier`).

| 부품 | 만드는 법 | 쓰는 곳 |
|---|---|---|
| `confetti` 꽃가루 | 캔버스 입자(사각·띠 모양, 중력·공기 저항·회전) | 경기 종료, 등급, 가입 |
| `firework` 폭죽 | 캔버스: 위로 쏘는 꼬리 → 터짐(입자 원형 분산, 잔상) | 홈런, 3점 이상, Lv.4~5, 대결 1등 |
| `sparkle` 반짝이 | CSS: 작은 별 SVG 5~8개가 퍼지며 사라짐 | 2루타, 승급 리본, 배지 |
| `banner` 띠 | CSS: 위에서 내려와 머물다 사라짐 | 플레이 볼, 환영 |
| `stamp` 도장 | CSS: 크게 → 원래 크기로 쾅, 살짝 기울기 | 최고 기록, 복습 완료 |
| `flip` 카드 뒤집기 | CSS 3D 회전(`rotateY`) | 등급 공개, 승급 |
| `countUp` 숫자 롤링 | 자바스크립트: 0→n, 0.6초 | 득점, 정답 수 |
| `trajectory` 공 궤적 | SVG 경로 + `offset-path` | 홈런 |
| `lightsOn` 조명 켜짐 | CSS: 밝기 서서히 | 스플래시, 전광판 |
| `crown` 왕관 낙하 | CSS: 떨어져 튕김 | 대결 1등 |

**효과 층**: 화면마다 따로 캔버스를 만들지 않고 앱에 하나(`<EffectsLayer>`), 맨 위 고정, 투명, `pointer-events: none`,
`aria-hidden`. 화면은 `celebrate('homeRun')`처럼 이름만 부른다 — 어떤 부품을 어떤 강도로 쓸지는 한 표(`effects/catalog.ts`)에 둔다.

## 4. 소리

1차에는 **소리 없음**. 2차 선택 사항: 설정에서 켤 때만(기본 끔), 브라우저 소리 합성(Web Audio)으로 "딱"(타격), "펑"(폭죽),
"와"(관중 — 소음 합성) — 녹음 파일을 쓰지 않아 저작권 문제가 없고 파일도 받지 않는다.

## 5. 얼마나 자주

- 큰 효과(●)는 한 판에 **최대 3번**. 넘으면 중간(◐)으로 낮춘다(홈런이 연달아 나와도 질리지 않게)
- 같은 효과가 0.5초 안에 다시 불리면 앞의 것을 이어 쓴다(겹쳐 터지지 않게)
- 한 화면에 입자 최대: 폰 120개, 큰 화면 220개. 낮은 사양(코어 4개 이하)이면 절반
- 탭이 가려지면(`visibilitychange`) 바로 멈추고 지운다

## 6. 접근성·설정

| 상황 | 효과 |
|---|---|
| 기기 "동작 줄이기"(`prefers-reduced-motion`) | 입자·궤적·흔들림·뒤집기 **끔**. 대신 결과 글자에 **색 띠·테두리**만(예: 홈런 금색 테두리), 숫자는 바로 최종값 |
| 앱 설정 **"화면 효과"**(새로 추가) | **켜기**(기본) · **줄이기**(작은 효과만, 폭죽 없음) · **끄기**. 기기 설정보다 앱 설정이 우선이 아니라 **둘 중 더 조용한 쪽** |
| 고대비 화면 | "줄이기"와 같게. 꽃가루 색은 쓰지 않음 |
| 화면 읽기 | 효과 층은 숨김. 지금 있는 `role="status"` 글자("홈런!", "Lv.3 주전")가 그대로 읽힌다. 승급 휘장만 대화상자로 알림 |
| 번쩍임 | 밝기 변화는 1초에 3번 이하, 화면의 큰 면적이 번쩍이지 않게(폭죽 잔상은 작은 점) |

"화면 효과" 설정은 기기에 저장한다(`yk_effects`). **기기 저장소 키가 늘어나므로 처리방침 §10의 기기 저장 항목에 함께 적는다**
(`privacy.test.ts`가 코드의 키와 처리방침 목록이 같은지 지킨다 — 빠뜨리면 테스트가 실패한다). 회원이어도 서버에 두지 않는다(쓰기 0).

## 7. 성능

- 효과 엔진은 **처음 축하가 필요할 때** 따로 받는다(`import()`). 홈 화면만 보는 사람은 받지 않는다. 받는 동안 첫 효과는
  CSS 부품만(이미 있는 CSS)으로 보여 준다
- 캔버스는 `devicePixelRatio`를 2로 제한, `requestAnimationFrame` 한 개로 모든 입자, 효과가 없으면 루프를 멈춘다
- 목표: 중급 안드로이드 폰에서 효과 중 프레임 50fps 이상, 효과 때문에 다음 버튼 반응이 100ms 넘게 늦지 않음(§8에서 측정)
- Hosting 무료 전송량: 엔진 약 3 KB, 스플래시 1.5 KB — 첫 방문 크기(약 460 KB)에 비하면 1% 안

## 8. 확인 방법

- 단위: 이벤트 → 강도 고르기(득점·등급·판당 큰 효과 횟수·설정·동작 줄이기 조합), 입자 상한
- E2E(360·1280): 홈런 판정 때 효과 층에 캔버스가 생기고 2초 안에 비워짐, 효과 중에도 "다음 타석"이 눌림, 동작 줄이기·"끄기"
  설정에서 캔버스가 생기지 않음, axe 위반 0, 승급 휘장 Esc로 닫힘
- 성능: Playwright CPU 4배 느리게 + 폰 화면에서 홈런·3점 종료 효과의 프레임 측정
- 눈으로: 밝은·어두운·고대비 화면, 구단 테마 몇 개에서 색이 묻히지 않는지
- 득점 구간(0 / 1~2 / 3+)은 실제 경기 기록 분포를 본 뒤 고친다 — 큰 효과가 열 판 중 한두 번 나오는 정도가 목표

## 9. 만드는 순서

| 차수 | 내용 | 대략 |
|---|---|---|
| **1차** | 효과 층·엔진(꽃가루·폭죽), 설정 "화면 효과", 처리방침 기기 저장 키, 로딩 스플래시, 플레이 볼 배너, **홈런·승급 리본**, 경기 종료 3단계, **등급 카드 뒤집기·등급별 폭죽** | 테스트 포함 하루 |
| 2차 | 나머지 타석 결과(주자 이동·아웃 등), 연속 배지, 친구 대결(카운트다운·왕관·순위), 오답노트 도장, 가입 환영, 개인 최고 기록 | 하루 |
| 3차 | 공식 XP를 켠 뒤 승급 휘장, 소리(선택) | 공식전 승인 뒤 |

## 10. 정해 주실 것

1. "화면 효과" 기본값 — **켜기**(권장) / 줄이기
2. 경기 종료 큰 효과 기준 — **3점 이상**(권장, 실제 분포 보고 조정) / 다른 값
3. 친구 대결 3·2·1 카운트다운 — **넣기**(권장) / 빼기
4. 소리 — **1차 없음, 2차에 기본 끔으로**(권장) / 아예 없음
5. 개인 최고 득점 "최고 기록!" — 2차(권장, 최고 득점을 어디에 둘지 정해야 함: 회원은 `summary`에 필드 추가 → 규칙·테스트
   변경, 비회원은 기기 저장 → 처리방침 항목 추가)
