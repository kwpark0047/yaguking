# 게임물관리위원회 등급분류 신청 준비 — 야구왕(앱인토스)

> **초안이다.** 신청·서약·결제는 운영자가 직접 한다(로그인, 수수료 결제, 제출). 2026-11-04 작성.
> 근거: 토스 안내 https://toss.im/apps-in-toss/blog/game_rating_classification (2025-11 글 — 지금 화면과 다를 수 있다).
> 아래 답은 **현재 미니앱판 코드 기준**이다. 내용이 맞는지 신청하는 분이 확인하고, 등급은 위원회가 정한다.

## 1. 먼저 확인할 것

- [ ] **채널톡 답변** — 게임 유형을 비게임으로 바꿀 수 있으면 등급분류가 필요 없을 수 있다. 수수료를 내기 전에 확인한다
- [ ] **신청 자격** — 안내 글: 개인 사업자는 업체 회원으로 로그인, 사업자는 **게임물제작업자등록증 또는 게임물배급업자등록증**을 낸다. 위마켓이 등록돼 있는지, 개인으로 낼 수 있는지 위원회에 묻는다
- [ ] **수수료** — 안내 글에 금액이 없다. 신청 화면의 수수료 계산으로 본다

### 게임 개요(붙여 넣기)

야구 상식 문제를 푸는 퀴즈 게임이다. 문제 하나가 공 하나이고, 네 개의 보기 중 하나를 시간 안에 고른다(첫 문제 20초, 다음부터 15초). 빨리 맞힐수록 안타·2루타·홈런으로 판정되고, 틀리거나 시간을 넘기면 아웃이다. 3아웃이면 1이닝이 끝나고 박스스코어(타율 등)를 보여 준다. 경기 중 가끔 타이밍 배팅·스트라이크 판정·초성 퀴즈 이벤트가 나온다. 날마다 같은 3문제를 푸는 "오늘의 1이닝", 틀린 문제를 다시 푸는 오답노트, 초대 코드로 함께 푸는 친구 대결이 있다. 무료이며 결제·경품·환전이 없고, 점수는 재화로 바꿀 수 없다.

| 공포 | 없음 | |
| 약물 및 범죄 | 없음 | 도박·약물 묘사 없음(문제은행 전수 검토는 안 함 — 아래) |
| 부적절한 언어 | 없음 | 친구 대결 이름은 이용자가 입력한다(비속어 거르는 기능 확인 필요) |
| 사행성 | 없음 | 결제·베팅·현금화 없음. 찬스 이벤트의 "타이밍 배팅"은 야구 타격이고 내기가 아니다 |

**신청 전 확인**: 문제은행 1,134문항을 내용정보 기준으로 전수 검토하지는 않았다. 낱말 검색(약물·도박·폭행·폭력·음주)에서는 규정 문항 1개가 걸렸다: "빈볼 폭행 도핑 위반으로 제재를 받으면 누구에게 제재금이 더 부과되는가?"(`data/questions.awards-and-ops.csv`). 친구 대결 이름에는 비속어를 거르는 기능을 찾지 못했다.
"타이밍 배팅"이라는 이름이 심의에서 베팅으로 읽힐 수 있으니 설명을 함께 적는다.

## 5. 등급을 받은 뒤 — 앱인토스 콘솔 › 게임 등급분류 탭

등록자명·자체등급분류사업자명, 등급분류일자·번호, 이용등급, 내용정보(위원회 결과 그대로), 대표자 인감 또는 사인 이미지, 게임 주요화면 2쌍(등급분류 화면 / 앱인토스 화면 — 같은 게임이어야 한다).
**등록자명과 사업자명이 다르면 반려**된다. 개인은 사유, 사업자는 등기부등본을 낸다.
