# 다시 오게 만들기 — 재방문 기능 기획(2026-11-02)

> 상태: **제안**(구현 전, 운영자 결정 대기). 출석·월간 등수·오늘의 공식전(`docs/engagement-plan.md`, 11-05 시작) 위에 얹는다.
> 지키는 것: Spark 무료(서버 코드·유료 API 없음), 기기가 계산한 점수는 공식 등수에 넣지 않음, 새로 모으는 개인정보는 처리방침 개정(7일 전 공지) 뒤.

## 0. 진단 — 왜 다시 오지 않나

| 사실(10-30~11-02) | 뜻 |
|---|---|
| 회원 2명, 비회원 36명(모두 최근 7일), 새 가입 0, 하루 경기 8판·참가 3명 | 사람 대부분이 **비회원**. 그런데 다시 올 이유(출석·등수·공식전)는 **회원에게만**, 그것도 11-05부터 |
| 앱을 닫으면 다시 부를 길이 없다 | 알림·메일·달력 어느 것도 없다. 홈 화면 앱(PWA)은 있지만 "오늘 할 것"을 알려 주지 않는다 |
| 결과를 남에게 보여 줄 길이 없다 | 공유 단추 없음 → 친구가 친구를 데려오는 고리가 없다 |
| 다시 올 이유가 이미 코드에 있지만 안 보인다 | 업적 카드 판정(`src/lib/achievements/rules.ts`, 6종)은 있는데 화면이 없다. 오답노트 복습 날짜는 오답노트 화면에 들어가야 보인다 |
| 재방문을 재지 않는다 | 관리자 하루 요약은 경기·참가·가입만. 무엇이 효과 있는지 알 수 없다 |

## 2. 권장 — 3단계

| 단계 | 무엇 | 왜 이 순서 |
|---|---|---|
| **1차(이번 주, 11-05 시작과 함께)** | **L 지표 · A 오늘의 1이닝+공유 · B 달력 알림 · C 오늘 복습 안내** | 비회원도 다시 올 이유가 생긴다. 무료·처리방침 개정 없음(기기 저장 키 한 줄만). 지표를 먼저 깔아야 2차를 고를 수 있다 |
| 2차(11월 중순, 1차 지표를 보고) | D 업적 화면 · E 복귀 보너스 · G 문항 도감 | 회원이 쌓을 것. 이미 있는 기록으로 계산 |
| 3차(처리방침 개정 공지 뒤) | F 주간 미션 · H 연속 지키기권 · I 웹 푸시 | 규칙·등수 계산·개인정보가 바뀐다 — 7일 전 공지 |

하지 않는 것: 실물 경품(engagement-plan §9-4), 친구 초대 보상(K), 끊김을 겁주는 문구("지금 안 오면 연속이 사라져요!" 같은 압박 알림).

## 3. 1차 상세

### A. 오늘의 1이닝 + 공유
- 홈 맨 위 카드 "오늘의 1이닝 — 3문제". 날짜(한국)로 문제은행에서 쉬움·보통·어려움 1개씩 고른다(모두 같은 문제, 규칙 문항은 1개까지). 한 번만 — 다시 열면 결과 카드
- 판정·화면은 개인 경기 그대로(첫 문제 20초 포함). 점수는 **비공식**, Firestore 쓰기 없음 — 비회원 하루 3판에 세지 않는다
- 결과 줄: `⚾ 야구왕 오늘의 1이닝 11/02` + 타석마다 🟩(안타 이상)·🟨(볼넷)·🟥(아웃) + `2안타 1아웃 · 연속 4일` + 앱 주소. 공유 단추(`navigator.share`, 없으면 복사)
- 기기 저장 `yk_daily`(최근 날짜·결과·연속 일수) — 처리방침 기기 저장 목록에 추가(개인정보 아님, 단위 테스트가 목록과 코드를 대조)
- 공식전과 겹치지 않게: 공식전 문항 풀(운영자 PC)과 무관, 공개 문제은행에서만

### B. 달력 알림
- 설정·홈 "매일 알림 받기" → 시각 고르기(기본 저녁 8시) → `.ics` 파일을 **기기에서 만들어** 받는다(서버로 아무것도 안 감). 반복 매일, 링크 = 앱 주소
- 아이폰·안드로이드·PC 달력이 알림을 띄운다. 끄기는 달력에서(안내 문구)

### C. 오늘 복습 안내
- 홈(회원)에 "오늘 복습할 문제 N개 →" — 오답노트 복습 시각이 지난 문서 수를 집계 쿼리로 센다(읽기 1). 0개면 숨김
- 홈 열기 읽기: 회원 5 → 6(매달 1일 7). 사용량 E2E 기대값을 함께 고친다

### L. 재방문 지표
- 운영자 PC 0시 작업(`daily`)에 추가: 어제 새로 온 계정 수, 그중 오늘 0시까지 다시 연(토큰 갱신) 수 → D1. 7일 전 새로 온 계정의 D7. 비회원·회원 따로
- 관리자 대시보드 "하루 요약"에 두 줄. 계정 사본(`accountMirror`)을 이미 매일 읽으므로 읽기 증가 없음

## 4. 비용(1차, 하루 1,000명 가정)

| 항목 | 읽기 | 쓰기 |
|---|---:|---:|
| A 오늘의 1이닝 | 0 | 0 |
| B 달력 알림 | 0 | 0 |
| C 오늘 복습(회원 홈 열기 1번) | +1/회원 | 0 |
| L 지표(운영자 PC) | 0 | 0(하루 요약 문서에 합침) |

전송: 오늘의 1이닝은 이미 받은 문제은행을 쓴다 → 추가 없음.

## 5. 정해 주실 것

1. **1차 범위** — **L·A·B·C(권장)** / A·B만 / 다른 조합
2. **공유 줄 모양** — 위 이모지 3색(권장) / 글자만
3. **달력 알림 기본 시각** — **저녁 8시(권장)** / 낮 12시 / 고르게만
4. **웹 푸시(I)** — 3차에 처리방침 개정과 함께 추진 / 하지 않음(권장: 1·2차 지표를 보고 정한다)
