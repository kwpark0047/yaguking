# 앱인토스 미니앱판

> 상태: **빌드까지 완료, 콘솔 앱 등록(`yaguking`, 게임 유형)·임시저장(2026-11-04), 출시 전**. 운영자 요청 — 앱인토스 미니앱으로 낼 수 있게 버전을 분리해 추가.
> 기준 문서: https://developers-apps-in-toss.toss.im (SDK `@apps-in-toss/web-framework` 3.9.0, 2026-11-04 확인).

## 1. 어떻게 나뉘어 있나

웹판(`yaguking.web.app`)·관리자 사이트와 **따로 빌드**한다. 웹판 묶음에는 토스 코드가 들어가지 않고, 웹판 동작은 바뀌지 않는다.
게임 화면·문제은행·판정은 `src/`를 함께 쓰므로 문제를 고치면 두 판에 함께 반영된다(미니앱은 다시 빌드·업로드).

| 파일 | 하는 일 |
|---|---|
| `vite.toss.config.ts` | 미니앱 빌드. 정책에 걸리는 모듈을 별칭으로 바꿔 끼운다(아래 표) → `dist-toss/` |
| `apps-in-toss.config.ts` | `appName`(콘솔 등록 이름과 같아야 함)·색·권한·내비게이션 바 |
| `toss/index.html`, `toss/main.tsx`, `src/toss/` | 미니앱 시작점·라우트·메인 화면 |
| `scripts/toss-check.mjs` | 묶기 전 점검: 공통 점검 + 구글 로그인·서비스 워커·설치 권유·달력·매니페스트가 없는지, 100 MB 이하 |
| `playwright.toss.config.ts`, `tests/toss/` | 미니앱 E2E(폰 360×740, 기기 어두운 모드) |

```bash
npm run toss:dev
```

```bash
npm run toss:build
```

`toss:build`의 결과는 `firebase-app/yaguking.ait`(커밋하지 않음). 콘솔 업로드 또는 `npx ait deploy`로 올린다.

## 2. 웹판과 다른 점 — 왜

| 정책(앱인토스 문서) | 미니앱판 |
|---|---|
| 로그인은 **토스 로그인만**, 소셜·자사 로그인 금지 | 구글·이메일 로그인 화면 없음. 가입 링크 숨김 |
| 토스 로그인은 **서버(mTLS)** 와 **사업자 등록** 필요 | "서버·유료 없음" 원칙과 맞지 않아 **이 판에는 없다** → 비회원 전용(§3) |
| 광고는 앱인토스 광고만, 외부·자체 광고 금지 | 광고 자리 없음(`src/toss/NoAd.tsx`) |
| 앱 설치 유도 금지 | 서비스 워커·매니페스트·즐겨찾기·설치 권유 없음 |
| 외부 링크 이동 제한, 토스 도메인 안에서 완결 | 바깥 주소 클릭 막음, 소식 출처는 글자로, 달력 파일·구글 캘린더 없음 |
| iframe 금지 | `src/toss/firebaseAuth.ts` — 휴대폰에서 구글 로그인용 숨은 iframe을 띄우는 처리기 없이 Auth 초기화 |
| 다크 모드 미지원 | 항상 밝은 화면, 테마 고르기 없음 |
| 공유는 `intoss://` | `src/toss/share.ts` — 토스 공유 시트·공유 링크(`Share.sendMessage`, `Share.createLink`) |
| 진입 직후 자동 창 금지 | 없음 |

## 3. 미니앱판에 있는 것·없는 것

- **있음**: 개인 경기(하루 3판), 오늘의 1이닝·공유, 오답노트·복습, 친구 대결, 소식, 공지, 처리방침
- **없음(회원 전용)**: 출석·월간 등수·오늘의 공식전·레벨 테스트·힌트(출석 포인트)·프로필
- 기록은 웹판과 같은 Firebase에 **익명 계정**으로 저장하고, 30일 안 쓰면 정리된다. 웹판 계정과 이어지지 않는다
- 앱을 지우거나 기기를 바꾸면 기록이 이어지지 않는다(토스의 `getAnonymousKey`는 같은 사용자에게 같은 값을 주지만, 클라이언트가 보낸 값은 믿지 말라고 문서가 안내해 Firestore 규칙으로 지킬 수 없다)

## 4. 운영자가 직접 할 일(출시 전)

1. 콘솔 앱 등록은 끝났다(워크스페이스 5551, `yaguking`, **게임 유형**). 이름·부제·상세 설명·출시 노트·이메일은 임시저장됨
2. **이미지 올리기** — 아래 표의 파일(파일 선택 창은 운영자가)
3. **게임 등급 정보(§5-1)** — 스토어 링크 또는 등급분류증명서, 대표자 정보, 인감 또는 사인 이미지
4. 검색 키워드, 메모(번들과 함께 저장되는 듯 — 임시저장에 남지 않았다)
5. **Firebase 허용 주소 확인** — 구글 클라우드 콘솔의 API 키 제한이 있다면 `https://yaguking.apps.tossmini.com`, `https://yaguking.private-apps.tossmini.com`을 넣는다(앱 이름이 다르면 그 이름으로)
6. `.ait` 업로드 → **토스앱 테스트(QR)** 한 번 이상 → 검토 요청(영업일 3~7일) → 출시

## 5. 위험·확인할 것

1. **게임으로 등록하면 게임물관리위원회 등급분류 증빙이 필요하다.** 문서에는 퀴즈가 게임인지 적혀 있지 않다. 화면에 "게임 시작"·1이닝이 있어 게임으로 볼 수 있다 → **앱인토스 문의로 먼저 확인**. 게임이면 등급분류를 받거나 문구·구성을 바꿔야 한다. 게임으로 등록하면 게임 체크리스트(닫기 단추, 소리 끄기, 종료 확인 창 등)를 다시 맞춰야 한다
2. **Firebase 익명 계정**이 금지된 "로그인 기능"인지 문서에 없다(화면에 로그인이 보이지 않아 괜찮을 것으로 보지만 확인 필요). 안 되면 Firestore 없이 기기 저장만 쓰는 판으로 줄인다(대결 제외)
3. **처리방침**: 미니앱에서도 같은 항목을 모으지만 토스 경유 안내가 없다. 검토 전에 문구를 정한다
4. **자체 나가기 단추**: 경기 화면의 "◀ 나가기"가 토스 내비게이션 바의 뒤로 가기와 겹친다. 검토 지적이 있으면 뺀다
5. **토스 앱에서만 확인되는 것**: 새로고침·딥링크(`intoss://yaguking/room/…`)로 하위 주소를 바로 여는 동작, 안드로이드 뒤로 가기, 공유 시트. 문서에 없어 QR 테스트로 확인한다
6. **문항 권리**: B구간(`docs/retention-plan.md`, 10 문서 §1.2)이 법적 검토 전이다. 토스라는 더 큰 유통 채널에 내기 전에 확인을 권한다
7. `npm audit`: SDK 설치로 경고가 늘었는지 출시 전에 본다
