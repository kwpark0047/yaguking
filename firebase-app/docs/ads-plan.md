## 0. 요약

| 무엇 | 어떻게 |
|---|---|
| 메인 | 맨 위(공지 띠 자리)에 **광고 한 칸**. 공지 띠는 **메인 맨 아래**(최신 소식 아래)로 |
| 게임 중 | 문제 카드 **아래**(화면에 고정하지 않음 — 보기와 떨어뜨려 잘못 누르지 않게)에 광고 한 칸. 개인 연습 경기만 |
| 등록 | 관리자 사이트 "광고": 위치·제목·문구·이동 주소·광고주·기간·**이미지(선택)**·대체 글. 이미지는 브라우저가 배너 크기로 줄여 저장 |
| 저장 | 무료 플랜 안: 광고 목록은 이미 앱 열기마다 읽는 공개 묶음(public/home)에, 이미지는 광고마다 작은 공개 문서 하나(≤ 120 KB) |
| 표시 | "광고" 표시 + 광고주, 새 창(`rel="sponsored noopener"`), 대체 글, 움직임 없음. 광고가 없으면 자리를 비우지 않고 아예 그리지 않음 |
| 하지 않음 | 외부 광고 네트워크(애드센스 등)·맞춤 광고·쿠키·추적 픽셀, 다른 사이트의 이미지 주소, 레벨 테스트·오늘의 공식전·친구 대결 중 광고 |

## 1. 자리(화면)

### 메인
```
[머리줄 ⚾ 야구왕 ☆ 로그인]
[광고 — 4:1 배너 또는 글 광고]   ← 지금 공지 띠 자리
[야구왕 히어로 · 게임 시작 …]
[이렇게 놀아요] [오늘 출석] [최신 소식]
[공지 띠]                          ← 맨 아래로
```
- 배너 비율 **4:1**(1200×300으로 저장, 화면 폭에 맞춰 줄어듦). 이미지가 없는 광고는 글 카드(제목·문구·단추)
- 공지 띠는 모양 그대로 맨 아래. 고정 공지는 그대로 맨 앞 하나

### 게임 중(개인 연습 경기 `/play`)
- 문제 카드·결과 단추 **아래**에 한 칸. 비율 **6:1**(960×160). 화면 아래 **고정하지 않는다**: 휴대폰에서 보기 단추 바로 밑에 붙으면 15초 안에 급히 누르다 광고를 누르게 된다
- 결과 화면(경기 종료)에도 같은 칸 하나. 찬스 이벤트 화면에서는 숨김(가운데 놀이에 집중)
- **넣지 않는 곳**: 레벨 테스트·오늘의 공식전(공정성·집중), 친구 대결(여러 사람이 같은 화면을 봄), 처리방침·로그인·가입·설정

## 2. 광고 한 건(데이터)

| 칸 | 규칙 |
|---|---|
| 위치 | `home-top`(메인 상단) / `play-bottom`(게임 중 하단) |
| 제목 | 1~30자(글 광고의 큰 글자, 이미지 광고면 화면 읽기용) |
| 문구 | 0~60자(글 광고의 한 줄) |
| 단추 글자 | 1~12자(예: "자세히 보기") |
| 이동 주소 | `https://…` 또는 앱 안 주소(`/ranking` 등). `javascript:` 등은 거절 |
| 광고주 | 1~30자(예: "야구왕", 협찬사 이름) — "광고 · 광고주" 로 표시 |
| 기간 | 시작·끝(한국 시각). 끝이 시작보다 뒤 |
| 이미지 | 선택. 저장은 줄인 WebP(§3). **대체 글 1~80자 필수** |
| 가중치 | 1~10 — 같은 자리에 광고가 여럿이면 앱을 열 때마다 가중치대로 하나를 고름 |
| 숨김 | 끄면 바로 내려감 |

- 원본 목록: `adminConfig/ads`(관리자만, 화면 읽기 1) — 지금의 공지·이벤트·소식과 같은 방식
- 앱이 읽는 것: 공개 묶음 `public/home`에 **지금 게시 중인 광고의 칸만**(이미지 제외, 광고당 몇백 바이트) — 이미 앱 열기마다 1번 읽는 문서라
  **읽기가 늘지 않는다**. 저장할 때 관리자 화면이 공지와 함께 다시 만든다
- 이미지: `public/ad_{광고ID}` 문서 하나(`data`: WebP data URL, 가로·세로, 판 번호). 보이는 광고의 이미지만 읽는다(읽기 +1, 앱을 연 동안 기억)

## 3. 이미지 등록(무료 플랜 안에서)

- **Firebase Storage는 쓰지 않는다**: 2024-10-30부터 새 저장 버킷은 Blaze(종량제)가 필요하다 → 이 프로젝트에서는 쓸 수 없다
- 관리자가 파일(PNG·JPG·WebP, 10 MB까지)을 고르면 **브라우저가** 자리 비율로 잘라·줄여(메인 1200×300, 게임 960×160) WebP로 바꾸고,
  **120 KB 이하**가 될 때까지 화질을 낮춘다 → 미리보기(실제 두 자리 모양)로 확인 → 저장. 원본은 어디에도 남기지 않는다(사진 위치 정보 같은 메타데이터도 사라짐)
- 다른 사이트의 이미지 주소는 받지 않는다: 이용자 접속 정보가 그 사이트로 가고(처리방침의 제3자 문제), 내용이 몰래 바뀔 수 있다
- 보안 규칙: `public/ad_*`는 누구나 읽기, 관리자만 쓰기(모양·크기 검사 — data URL이 `data:image/webp;base64,`로 시작, 160,000자 이하)
- 비용: 이미지 한 장 ≈ 40~120 KB. 하루 1,000번 앱 열기 × 이미지 1장 ≈ 하루 최대 120 MB 전송 — Firestore 무료 전송(월 10 GiB) 안이지만 크다 →
  **광고 이미지 전체를 하루 3장 이하로 게시**(권장), 화면에 "이 광고 이미지 ○○ KB" 표시

## 4. 보여 주기 규칙

- **"광고"** 글자와 광고주를 늘 함께(표시광고법 취지) — 배너 왼쪽 위 작은 띠
- 링크: 바깥 주소는 새 창 + `rel="sponsored noopener noreferrer"`, 앱 안 주소는 그대로 이동
- 접근성: 구역 이름 "광고", 이미지 대체 글 필수, 누르는 곳 44px 이상, 움직임·깜빡임 없음(GIF·애니메이션 WebP는 저장 전에 첫 장면만)
- 효과 설정 "끄기"·동작 줄이기와 무관하게 늘 정지 화면
- 같은 광고를 계속 보이지 않게: 앱을 열 때마다 가중치로 하나 — 기기에 노출 기록은 남기지 않는다(처리방침의 기기 저장 항목이 늘지 않게)

## 5. 광고 내용 기준(관리자 화면에 늘 보임)

- 자체 광고(야구왕 기능·이벤트 안내)와 **계약한 협찬 광고**만. 외부 광고 네트워크 없음
- 금지: 청소년 유해(주류·담배·도박·사행성·성인), 의료·금융 과장, 실제 선수 사진·구단 로고(권리 확인 전), 다른 회원 정보
- 협찬 광고는 계약서·광고주 표시 확인 뒤 운영자가 올린다

## 6. 처리방침·법

- 지금 처리방침 2절: "광고나 방문 분석 도구도 쓰지 않습니다" → **"외부 광고 네트워크나 방문 분석 도구는 쓰지 않습니다. 운영자가 직접 올리는 광고(자체·협찬 광고)를
  보여 줄 수 있으며, 광고를 위해 개인정보를 수집하거나 다른 곳에 보내지 않습니다."**로 바꾼다 — 수집 항목은 늘지 않는다
- 바꾸는 시점(§9-6): 이미 예고 중인 11-05 판에 함께 넣으면 시행일을 하나로 유지(오늘 넣어도 시행 7일 전 기준을 거의 지킨다 — 11-05까지 7일)
- 클릭 수를 세면(§9-4) 광고별·날짜별 숫자만(누가 눌렀는지는 남기지 않음) — 개인정보 아님

## 7. 관리자 화면 "광고"

- 목록: 위치·상태(게시 중/예약/끝남/숨김)·기간·이미지 크기, 고치기·숨기기·지우기. 열 때 문서 하나(읽기 1)
- 쓰기: 위 칸들 + 이미지 고르기 → 자동 줄이기 → **두 자리 미리보기**(실제 크기) → 저장
- 저장하면 공개 묶음(public/home)을 공지와 함께 다시 만들고, 관리자 기록("광고 올림·고침·지움")에 남긴다
- 게시 중 광고 이미지가 하루 3장을 넘으면 경고

## 8. 확인 방법(만들 때)

- 단위: 광고 칸 검사(길이·주소·기간), 가중치 고르기, 게시 중 거르기, 이미지 줄이기(크기·형식)
- 규칙: 광고 원본은 관리자만, 공개 이미지 문서는 누구나 읽기·관리자만 쓰기(모양·크기)
- E2E: 관리자가 글 광고·이미지 광고 올림 → 메인 상단·게임 하단에 "광고" 표시와 함께, 공지가 맨 아래, 레벨 테스트·공식전·대결에는 없음, 숨기면 사라짐,
  광고 없을 때 빈 자리 없음, axe, 사용량(메인 읽기 그대로 + 이미지 1)

## 9. 정해 주실 것

1. **이미지 저장** — **Firestore에 줄여서(권장, 무료 — 관리자 화면에서 바로)** / 배포로 올림(관리자 등록 불가) / 다른 사이트 이미지 주소(권장하지 않음)
2. **게임 중 광고 위치** — **문제 카드 아래, 화면에 고정하지 않음 + 결과 화면에도(권장)** / 화면 맨 아래 고정
3. **광고 종류** — **자체 광고 + 계약한 협찬 광고(권장)** / 자체 광고만
4. **클릭 수 세기** — **1차는 세지 않음(권장)** / 광고별 하루 클릭 수만(누른 사람은 기록 안 함, 누를 때마다 쓰기 1)
5. **공지 띠 위치** — **메인 맨 아래, 최신 소식 아래(권장)** / 최신 소식 위
6. **처리방침 문구** — **11-05 판에 함께(권장)** / 따로 새 판(시행 7일 뒤)
