## 지킨 것

- 서버·외부 서비스 없음. 새로 모으는 정보 없음. S2는 기존 지갑 칸에 더하는 것이라 처리방침 개정판(시행 = 시작일)에 문장만 더했다
- 비공식 연습 점수를 등수에 넣지 않는다. 등수 추정("이 점수면 몇 위")은 연습 점수와 등수 포인트가 달라 넣지 않았다
- 읽기: S3는 비회원 홈에서 등수 문서 1번(10분 기억, 등수 화면과 같은 읽기). S1·G2는 0

## 검증

- 단위: 시작일·값이 화면과 운영 작업에서 같음, 처리방침 시행판에만 적힘, 권유 조건, 카드 요약 글
- 운영(에뮬레이터): 시작일 전 없음, 시작일부터 회원마다 50P, 다시 돌려도 한 번, 닉네임 없는 계정 제외, 기존 지갑 테스트는 그대로
- E2E(`tests/e2e/signup-boost.spec.ts`): 미리보기·가입 화면 이동·계정 안 만듦, 오늘의 1이닝 권유와 PNG 내려받기, 개인 경기 권유. **로컬에서는 돌리지 못했다**(이 PC의 8080 포트를 WSL이 써서 앱이 에뮬레이터에 붙지 못함) — PR CI에서 확인
