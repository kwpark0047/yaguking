# 야구왕(YaguKing) 보안 문서

## 보안 설계 원칙

### 1. 개인정보 최소 수집

- IP 원문은 DB에 저장되지 않음. HMAC-SHA256 해시만 보관.
- 게스트 토큰도 해시로만 저장.
- 로그에 토큰, 쿠키, 개인정보를 기록하지 않음.

### 2. IP 위조 방지

`X-Forwarded-For` 헤더의 첫 주소는 클라이언트가 임의로 설정할 수 있으므로 사용하지 않음.

신뢰 프록시 수만큼 오른쪽에 위치한 주소를 사용:
```
클라이언트 IP → 프록시 1 → 프록시 2 → 애플리케이션
                                    ↑ 신뢰 프록시 수=2일 때 이 위치 사용
```

### 3. 정답 보호

정답과 해설은 `private` 스키마에 저장. `PublicQuestion` 타입에는 정답 필드가 타입 레벨에서 존재하지 않음.

경기 종료 시에만 `loadReveal()`로 정답 조회 가능.

### 4. 트랜잭션 기반 원자성

모든 게임 쓰기 작업은 단일 DB 트랜잭션 내에서 처리. 부분 실패 시 전체 롤백.

### 5. 멱등성

중복 실행 방지를 위한 멱등 키 사용:
- XP 지급: `reason:entityId:userId`
- 타석 제출: `submission_id`

## 레이트 리밋

| 엔드포인트 | 버킷 | 제한 | 윈도 | 목적 |
|------------|------|------|------|------|
| 경기 시작 | `play.start` | 6회 | 60초 | 자동화 반복 호출 방지 |
| 타석 제출 | `play.submit` | 120회 | 60초 | 비정상 속도 제출 방지 |
| 게스트 승계 | `auth.claim` | 10회 | 60초 | 가입 직후 승계 제한 |

카운터 조작 실패 시 요청을 통과시킴 (가용성 우선).

## 게스트 체험 제한

- 1일 2이닝 (게스트 토큰 단위)
- 쿠키 삭제 시 우회 가능 → **보안 경계가 아닌 전환 유도 장치**
- 공식 모드는 회원 전용

## 만 14세 확인

회원 전용 모드 이용 전 만 14세 확인 필요. 확인 전에는 회원 기록을 쌓지 않음.

## 환경 변수 보안

프로덕션 배포 전 필수 확인:

| 변수 | 위험도 | 조치 |
|------|--------|------|
| `GUEST_TOKEN_SECRET` | 높음 | 32자 이상 안전한 값으로 변경 필수 |
| `SUPABASE_SERVICE_ROLE_KEY` | 높음 | 프로덕션 값으로 교체 |
| `DATABASE_URL` | 높음 | 비밀번호 포함, 노출 금지 |
| `RATE_LIMIT=off` | 중간 | E2E 전용, 프로덕션에서 제거 |

## 오류 처리 보안

- 소유자 확인이 실패하면 `NOT_FOUND` 반환 (존재 여부 노출 방지)
- 500 에러는 오류 코드만 로그에 기록 (상세 정보 미노출)
- 검증 실패 메시지는 사용자에게 표시 가능하지만 민감정보 미포함

## 취약점 점검

```bash
npm run security:check
```

## 알려진 보안 이슈

## 사고 대응

보안 사고 발생 시:
1. `GUEST_TOKEN_SECRET` 즉시 교체 (모든 게스트 세션 무효화)
2. 의심스러운 IP 차단 (프록시 구성 확인)
3. DB 로그 검토 (pg_stat_activity)
4. 영향을 받은 사용자 알림
