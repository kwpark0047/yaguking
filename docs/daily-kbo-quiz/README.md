## 요약

- 공개된 공식 API를 찾지 못했고, 약관과 robots.txt가 자동 수집을 막는다. **권한 없는 수집은 만들지 않는다.**
- 나머지(검증, 생성, 승인, 비회원 화면, 지표)는 출처와 분리해 지금 만들 수 있다.
- 서버 없이도 "답을 낸 뒤에만 정답을 읽는" 규칙으로 정답을 보호하면서 바로 결과를 보여 줄 수 있다.
- 비회원 시도 기록은 처리방침 개정이 필요해 시작이 배포 + 7일 뒤다. 그때는 비시즌이므로 첫 화면은 "2026 시즌 돌아보기"가 된다.
