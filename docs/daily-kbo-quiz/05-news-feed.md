# 소식 가져오기와 소식 → 문제 초안

- 2026-11-08 구현(배포 전). 운영자 결정: **언론사 RSS 정기 수집**, 문제는 **틀 기반 초안 + 관리자 확정**.
- 이 결정으로 운영 원칙 "실제 KBO 기록은 이용 권한 확보 전 자동 수집하지 않는다"를 아래처럼 좁혀 적는다.
  - KBO 공식 사이트(koreabaseball.com)의 자동 수집은 **계속 하지 않는다**(약관 제14조·robots.txt). 화면·운영 작업이 이 주소를 거절한다
  - 언론사 RSS는 **관리자가 이용 조건을 확인했다고 표시한 피드만** 하루 한 번 읽는다
  - 경기 기록(박스스코어)을 모으지 않는다. 기사 제목·링크·발행 시각·짧은 요약만 남긴다

## 1. 흐름

```
관리자: 피드 등록(이름·RSS 주소·이용 조건 주소·"확인함")
  → 운영자 PC 0시: robots.txt 확인 → RSS 1회 요청 → 제목·링크·시각·요약(200자) → newsItems(관리자만)
  → 관리자: 소식 고르기 → 정답이 될 사실 입력(구단/숫자/직접) → 틀이 오답·순서 채움 → "어제의 퀴즈" 묶음에 초안으로
  → 관리자: "어제의 퀴즈"에서 정답·출처 확인 → 승인 → 그날 06:00 공개
```

## 2. 지키는 것

| 항목 | 방법 |
|---|---|
| 등록 불가 주소 | koreabaseball.com과 하위 주소, http. 화면(`src/lib/news/feeds.ts`)과 운영 작업(`ops/newsFeed.mjs`)이 같은 검사(테스트가 대조) |
| 이용 조건 | "이용 조건을 확인함" 표시와 확인한 주소가 없으면 읽지 않는다 |
| robots.txt | 피드마다 먼저 확인. 막혀 있거나 받지 못하면(5xx·연결 실패) 건너뛴다. 없으면(4xx) 허락 |
| 요청 | 피드마다 하루 1번, 이름을 밝힌 User-Agent(`YaguKingFeedBot/1.0`), 15초 제한 |
| 저장 | 제목(200자)·링크(https)·발행 시각·요약(200자, 태그 제거). 기사 전문 없음. 14일 뒤 삭제. 관리자만 읽고 기기는 아무도 쓰지 못한다 |
| 이용자에게 | 소식 자체는 보이지 않는다. 문제의 해설은 관리자가 쓰고, 출처 링크를 단다 |
| 개인정보 | 다루지 않는다(처리방침 변경 없음) |

## 3. 문제 초안(AI 없음)

| 정답 종류 | 관리자가 넣는 것 | 틀이 채우는 것 |
|---|---|---|
| 구단 | 정답 구단 | 다른 구단 3개(실제 구단 이름) |
| 숫자 | 정답 숫자·단위 | 가까운 숫자 3개(같은 단위, 0 이상) |
| 직접 | 정답 + 오답 3개 | 순서만. 선수 명단 DB가 없어(권리 문제) 사람이 적는다 |

문제·해설은 관리자가 쓴다(해설 기본값은 기사 제목). 출처는 소식의 신문 이름과 링크, 기준일은 발행일이다. 묶음에 더하면 그 묶음은 초안으로 돌아가 다시 승인해야 한다. 공개된 묶음에는 더할 수 없다.

## 4. 운영자가 할 일

- [ ] 쓰려는 언론사 RSS의 이용 조건을 읽는다. 상업 서비스(광고가 있음)에서 제목·링크를 보여 주거나 문제로 바꾸는 것이 허용되는지 확인한다. 비상업 개인 이용만 허락하는 곳은 등록하지 않는다
- [ ] 관리자 "소식 가져오기"에서 피드를 등록한다(기본 피드는 넣어 두지 않았다)
- [ ] 다음 0시 작업 뒤 가져오기 기록을 확인한다. 바로 보려면 운영자 PC에서 `node ops/admin-cli.mjs news-feed --project=yaguking-bc25c`

## 5. 검증

- 단위: 피드 읽기(RSS·Atom·CDATA·엔티티로 감싼 HTML), robots.txt 해석, 등록 불가 주소, 초안 만들기(구단·숫자·직접, 잘못된 입력)
- 운영(에뮬레이터·가짜 fetch): 조건별 건너뛰기(꺼짐·미확인·KBO·robots·받기 실패), User-Agent, 다시 돌려도 겹치지 않음, 14일 삭제
- 규칙: 소식은 관리자만 읽고 아무도 기기에서 못 씀, 피드 목록은 관리자 20개까지
- E2E(`tests/e2e/kbo-admin.spec.ts`): KBO 주소 거절 → 피드 등록 → 구단 문제 초안 → 묶음에 더해짐. **로컬에서는 돌리지 못했다**(이 PC의 8080 포트를 WSL이 쓰고 있어 앱이 에뮬레이터에 붙지 못함). PR CI에서 확인한다
