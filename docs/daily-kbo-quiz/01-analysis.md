# 1단계 분석 — 지금 코드에 있는 것과 없는 것

- 작성 2026-11-05. 대상: `firebase-app/`(운영 중인 Firebase판). 상위 폴더의 Next.js 앱은 건드리지 않는다.
- 코드와 규칙을 직접 읽고 쓴 내용이다. 실제 운영 DB는 조회하지 않았다.

## 1. 구조

| 항목 | 현재 | 근거 |
|---|---|---|
| 프레임워크 | React + Vite + react-router(정적 사이트). Next.js가 아니다 | `src/pages/*`, `vite.config` |
| 호스팅 | Firebase Hosting 3개(앱·관리자·옛 주소 이동) | `firebase.json` |
| 인증 | 이메일·구글·익명 | `src/lib/auth/actions.ts` |
| DB | Firestore. 서버 방어는 보안 규칙뿐 | `firestore.rules` |
| Functions | **없음.** Spark 유지 조건 | 운영 원칙 |
| 스케줄러 | 운영자 PC 작업 "YaguKing cleanup", 매일 00:00(`ops/run-cleanup.cmd`). PC가 켜져 있어야 돈다 | `ops/` |
| GitHub Actions | CI 있음. `firebase-cleanup.yml`은 꺼진 채로 있음(수동 실행만). 저장소는 공개 | `.github/workflows/` |

## 2. 문제와 정답

| 종류 | 저장 위치 | 정답 위치 | 채점 |
|---|---|---|---|
| 일반 문제은행 1,134문항 | 앱에 묶인 정적 JSON(`data/*.csv` → `npm run content:build`) | **기기에 있음** | 기기(그래서 비공식) |
| 오늘의 1이닝 | 문제은행에서 날짜로 3문제 | 기기 | 기기, Firestore 안 씀 |
| 공식전 | `officialRounds/{id}/questions/{i}` 하나씩 공개 | `officialKeys`(아무도 못 읽음) | 운영자 PC가 다음 날 |

→ **기기에 정답을 숨기면서 답을 내자마자 결과를 보여 주는 경로는 아직 없다.** 공식전은 숨기지만 결과가 다음 날이다. 이번 기능의 핵심 설계 지점이다(`03-design.md` §3).

## 3. 비회원과 회원

| | 비회원(익명 로그인) | 회원 |
|---|---|---|
| 개인 경기 | 하루 3판(규칙으로 제한) | 제한 없음 |
| 공식전·월간 등수·출석 | 불가 | 가능 |
| 점수 공식 반영 | 안 됨 | 공식전만 |
| 가입 시 기록 | `linkWithCredential`로 **같은 uid** 유지 → 기록이 그대로 이어짐 | — |

`ops/cleanup.mjs`가 30일 쓰지 않은 비회원 계정과 기록을 지운다. 탈퇴 시 지우는 목록은 `src/lib/profile/save.ts`에 있다.

## 4. 경기 기록 수집 — 없음

- 자동 수집 코드는 **하나도 없다.** 구현된 기능이 아니라 일부러 막아 둔 것이다.
- 최신 문항은 `data/questions.recent-2026.csv` 11개뿐이다. 공개 보도를 사람이 확인해 쓰고 `source_url`·`verified_at`·`rights_note`를 남겼다.
- 소식(`ops/news.mjs`)은 사람이 쓴 글의 출처·날짜를 밤에 확인해 `public/news`로 올린다. 파일 첫머리에 "리그 경기 소식은 데이터 이용 허락 전까지 없음"이라고 적혀 있다.
- 문항 권리 구간(`KBO_YaguKing_Docs_20261023/10_문항확보_및_P2_착수계획.md`): A 규정, B 공표된 사실(법적 검토 대기, 운영자가 B까지 쓰기로 결정), **C 상세 기록·"그날의 야구" = 기록 DB 사용권 필요, 불가.**

## 5. 재사용할 수 있는 것

| 이번 요구 | 재사용 | 고칠 점 |
|---|---|---|
| 한 문제씩 공개, 답 고치기 금지 | `officialRounds` 규칙과 시도 문서 구조 | 회원 전용을 비회원까지. 정답 공개 규칙 추가 |
| 문제 풀이 화면 | `QuestionView` | 그대로 |
| 사람 확인·공개 흐름, 출처 검사 | `src/admin/pages/NewsPage.tsx`, `ops/news.mjs` | 경기·문항용 화면 신설 |
| 관리자 권한 | 규칙의 `isAdmin()`, 관리자 사이트 세션 | 그대로 |
| 작업 실행 기록 | `adminLogs`, `adminTasks` 큐 | 큐는 PC가 돌 때만 처리된다(즉시 실행 불가) |
| 지표 집계 | `ops/admin.mjs`의 `adminDaily`, 재방문율 D1/D7 | 항목 추가 |
| 만료 데이터 삭제 | `ops/cleanup.mjs` | 대상 추가 |
| 가입 유도 | 힌트의 가입 안내, 개인 경기 제한 화면 | 문구만 |

## 6. 겹치거나 부딪치는 것

| 번호 | 내용 | 어떻게 할지 |
|---|---|---|
| 1 | **자동 수집이 운영 원칙과 충돌**: "실제 KBO 기록은 이용 권한을 확보하기 전까지 자동 수집하지 않는다" | 결정 필요. `02-data-source-report.md` |
| 2 | 원문의 난이도 비율 50·35·15와 문제은행 비율은 별개 | 이 세트에만 적용 |

| 4 | 분석 도구가 없고 처리방침은 외부 분석 도구를 쓰지 않는다고 적음 | 외부 도구 없이 시도 문서로 집계(`03-design.md` §6) |
| 5 | 비회원의 시도 기록은 새로 모으는 정보 | 처리방침 개정, 7일 전 공지 |
| 6 | 시즌 일정: 한국시리즈가 늦어도 11-11에 끝나고 이후 비시즌 | 경기 없는 상태가 기본값. 다음 정규 경기는 2027 시즌(일정 미확인) |
| 7 | 토스 미니앱은 비회원 전용이고 게임 등급분류 진행 중 | 1차는 웹판만. 토스판은 등급 뒤 결정 |
