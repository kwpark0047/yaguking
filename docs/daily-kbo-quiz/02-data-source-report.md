# 데이터 출처 보고 — 수집 전에 먼저 정할 것

- 작성 2026-11-05. 아래 사이트는 이날 다시 열어 확인했다. **법률 자문이 아니다.** 약관 해석은 법무 확인이 필요하다.
- 요구서 §3: "공식 API가 확인되지 않았다면 임의의 API 엔드포인트를 만들지 마세요. 수집 방식, 이용 조건, 출처, 갱신 주기 및 장애 대응 방안을 먼저 보고하세요."

## 결론

**공개된 공식 API를 찾지 못했다. 지금 합법적으로 자동 수집할 경로가 없다.** 그래서 수집 코드는 만들지 않았고, 사이트 내부 데이터 경로도 분석하지 않았다.

## 3. 권장안

1. **지금** 문의서를 보낸다(운영자가 직접. 비시즌 넉 달이 협상 시간이 된다).
2. **그동안** 데이터 출처와 분리된 흐름을 테스트 데이터로만 만든다. 정답 보호, 관리자 승인, 비회원 화면, 지표까지 끝내 둔다. 계약이 되면 어댑터 하나만 붙인다.
3. **이번 비시즌 화면**은 "2026 시즌 돌아보기"로 연다. 이미 쓰기로 정한 구간 B 사실(시즌 순위, 한국시리즈 결과)을 사람이 확인해 쓴다. "어제"라고 표시하지 않고 날짜를 적는다.
4. **2027 개막 전**에 다시 판단한다. 계약이 되면 A, 안 되면 법무 확인 뒤 B, 둘 다 안 되면 돌아보기만 유지한다.
