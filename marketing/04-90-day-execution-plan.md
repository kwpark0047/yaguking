## 2. 90일 요약 (60초 판)

**포지셔닝 한 줄:** "규칙부터 기록까지, 야구 지식을 한 이닝 경기로 겨루는 KBO 팬 퀴즈."

**상황 판단:** 비시즌(11~1월)이라 경기 화제가 적고, 무료 한도 때문에 하루 1,000명 안팎이 상한이다. 그래서 90일 목표는 "많이 모으기"보다 **한도 안에서 매일 돌아오는 팬 300명을 만들고, 그 팬이 친구를 데려오는지 확인하기**다. 2월 스프링캠프·3월 개막 때 확대할 수 있는 근거를 만드는 기간이다.

**세 가지 베팅**

1. **11/5 시즌 오픈을 첫 발표로 쓴다.** 출석·월간 등수·구단 대항전을 "11월 시즌 개막"으로 묶어 소개한다. 이후 매월 1일이 새 시즌 발표 계기가 된다(12/1, 1/1).
2. **구단 대항전을 바이럴 축으로 쓴다.** 팬덤끼리의 순위 경쟁은 개인 점수보다 공유 동기가 강하다. 매주 "이번 주 출석 1위 팬덤" 카드를 직접 만들어 배포한다.
3. **찬스 이벤트·규칙 문항을 숏폼 소재로 쓴다.** 초성 퀴즈·스트라이크/볼 판정은 15초 영상으로 바로 보여 줄 수 있고 권리 문제가 없다.

**90일 성공 기준** — 기준선 2명 반영으로 05 문서 §3이 대체. 아래 표는 무료 한도에 가까워질 만큼 성장했을 때(개막 시즌 이후) 참고용으로 남긴다.

| 지표 | 90일 목표 | 비고 |
|---|---|---|
| 주간 경기 완료 고유 사용자(북극성) | 기준선 대비 3배, 또는 주 500명 | 한도 상 일 1,100명 이하 유지 |
| 출석 7일 이상 회원(월간) | 12월 150명, 1월 300명 | 관리자 출석 집계 |
| 구단 대항전 참여 구단 | 10개 구단 모두 최소 인원(`TEAM_MIN_FANS`) 충족 | 한 구단 쏠림 방지 |
| 친구 대결 완료 판수 | 주 50판 | 한도: 하루 수백 판 이하 |
| 비회원 → 회원 전환 | 기준선 +30% 상대 개선 | 3판 소진 시점 측정 |
| 일일 쓰기 사용량 | 1만 4천(한도의 70%) 이하 상시 유지 | 넘으면 외부 홍보 일시 중단 |

**예산:** 유료 광고 0원. 도구 신규 구독 0원. 경품을 쓴다면 운영자가 정한 상한 내 소액 기프티콘만(§9 결정 대기).

## 3. 공통 메시지 키트

모든 채널은 아래 문장에서 골라 쓴다. 검증 안 된 수치·공식 제휴 암시는 쓰지 않는다.

| 쓰임 | 문구 |
|---|---|
| 한 줄 소개 | 야구 퀴즈를 한 이닝 경기로. 맞히면 안타, 틀리면 아웃, 3아웃이면 경기 끝. |
| 규칙 강조 | 인필드 플라이, 보크, 낫아웃. 헷갈리던 규칙을 한 이닝에 정리해요. |
| 시즌 오픈(11/5) | 11월 시즌 개막. 매일 출석하고, 내 구단을 이번 달 1위 팬덤으로 만들어 주세요. |
| 구단 대항전 | 이번 주 출석 1위 팬덤은 ○○. 우리 구단은 몇 위일까요? |
| 친구 대결 | 방 코드 6자리면 끝. 단톡방에서 바로 야구 지식 대결. |
| 가입 권유(3판 소진 후) | 오늘 비회원 경기는 여기까지. 가입하면 기록이 남고 출석·등수에 들어가요. |
| 큰 글자 | 글자가 기본부터 큼직해요. 부모님과 같이 해도 좋아요. |

**쓰지 않는 말:** "KBO 공식", "공식 기록 인증", "실시간 순위"(월간 등수는 밤 작업으로 하루 한 번 갱신), "○만 명이 즐기는", 구단·선수 로고와 사진, 특정 팬덤 조롱.

**출처 원칙:** 기록·역사 문항을 콘텐츠로 쓸 때는 기준일과 출처를 함께 적는다. 규칙 문항은 "야구 규칙 해설"로 직접 쓴 문장만 쓰고 규칙서 원문을 길게 옮기지 않는다.

## 6. 측정과 주간 회고

분석 SDK가 없으므로 **관리자 사이트 + Firebase 콘솔 + 짧은 링크 클릭 수**로 잰다. 수작업이므로 지표를 7개로 제한한다.

**주간 기록표(매주 일요일)**

| 주차 | 주간 경기 완료 사용자 | 신규 가입 | 출석 회원 수 | 친구 대결 완료 판 | 최대 일 쓰기(한도 대비 %) | 채널 링크 클릭 합 | 문항 신고 |
|---|---|---|---|---|---|---|---|
| 기준선(11/2) | | | — | | | — | |
| 1주차 | | | | | | | |
| … | | | | | | | |

**계산 규칙**

- 비율은 같은 기간끼리 나눈다. 예: "가입 전환율" = 그 주 첫 경기를 한 비회원 중 같은 주에 가입한 수 ÷ 그 주 첫 경기를 한 비회원 수
- D7 같은 재방문 비율은 7일이 다 지난 코호트만 분모에 넣는다. 진행 중인 코호트는 "대기"로 표시
- 표본이 30명 미만이면 비율 대신 원래 숫자를 적고 결론을 미룬다

**중단 기준(kill criteria)**

| 활동 | 중단 조건 |
|---|---|
| 특정 커뮤니티 게시 | 3회 연속 링크 클릭 5회 미만, 또는 운영 규칙 위반 경고 1회 |
| 숏폼 | 4편 연속 조회가 채널 평균의 절반 미만 |
| 블로그 | 8편 뒤에도 검색 유입 클릭이 주 10회 미만이면 격주로 축소 |
| 외부 홍보 전체(일시) | 일 쓰기 1만 4천 초과 또는 무료 한도 도달 |

**주간 회고 20분 순서:** 기록표 채우기(5분) → 한도 확인(2분) → 이번 주 가장 반응 좋았던 게시물 1개와 이유(5분) → 다음 주 바꿀 것 1개(5분) → 결정 기록(3분).
