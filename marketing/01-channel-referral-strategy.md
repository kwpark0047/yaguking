# 야구왕 90일 채널·바이럴 전략

**기간:** 2026-11-01 ~ 2027-01-29  
**원칙:** 무료 채널 우선, 팬 커뮤니티 규칙 준수, 검증된 문항과 자체 자산만 사용, 미구현 기능을 현재 기능처럼 홍보하지 않음.

## 1. 90일 목표와 큰 베팅

야구왕은 유료 광고보다 제품 안의 “한 이닝 완료”, “친구 대결 초대”, “구단 대항전 출석”을 성장 루프로 만드는 편이 먼저다. 90일 동안 다음 세 가지를 검증한다.

1. **검색 가능한 신뢰 자산:** 검수된 문항을 네이버 블로그의 설명형 콘텐츠로 축적한다.
2. **대화형 팬 콘텐츠:** Facebook·X·Threads에서 퀴즈와 팬 대화를 만들고 첫 경기로 연결한다.
3. **제품 내 초대:** 친구 대결과 구단 대항전이 신규 완료 사용자와 재방문을 만드는지 측정한다.

성공은 팔로워 수가 아니라 `신규 방문 → 첫 경기 완료 → 회원가입 완료 → 7일 내 재완료 → 친구 대결 초대 완료`의 개선으로 판단한다.

## 2. 90일 단계별 전략

| 기간 | 초점 | 실행 | 다음 단계 조건 |
|---|---|---|---|
| 1~2주 | 기반·신뢰 | 11/05 기능 스모크 테스트, 약관/권리/분석 게이트, UTM 규칙, 15명 고객 연구 모집, 소셜 프로필·고정글 정리 | 기능·문구가 실제와 일치, 최소 측정안 승인 |
| 3~4주 | 콘텐츠 기반 | 네이버 블로그 주 2편, Facebook 주 3회, X 주 5회, Threads 주 4회. 문항 1개를 4채널로 재가공 | 4주 발행 지속, 채널별 클릭/게임 시작 관찰 |
| 5~8주 | 초대 실험 | 친구 대결 주간, 구단별 출석 집결 포스트, 커뮤니티 운영자 3~5명에게 비금전 협업 제안 | 초대 방문→방 참가→완료 퍼널 확보 |
| 9~12주 | 반복 루프 | 성과 상위 주제 2개 집중, 주간 구단 대항전 요약, PWA 저장 안내, 재방문 메시지 실험 | D7·초대 완료 기여가 기준선 대비 개선 |
| 13주 | 회고 | 채널별 유입·완료·재방문·운영시간, 사용량·신고·권리 이슈 정리 | 확대/유지/중단 결정 |

## 3. 콘텐츠 포트폴리오

| 기둥 | 비중 | 역할 | 예시 |
|---|---:|---|---|
| 한 문제 한 타석 | 35% | 즉시 참여·첫 클릭 | 문제 공개 → 보기 → 다음 날 해설/출처 |
| 규칙·기록 해설 | 25% | 신뢰·검색 자산 | “노게임이면 입장권은?” 같은 검수 문항 설명 |
| 구단·친구 대결 | 20% | 초대·팬 정체성 | “같은 구단 팬 3명을 모으면 순위가 열린다” |
| 제작·운영 비하인드 | 10% | 신뢰·인간성 | 왜 비공식 점수인지, 출처를 어떻게 검수하는지 |
| 제품 안내 | 10% | 활성화 | 비회원 3판, 레벨 테스트, 오답노트, PWA 저장 |

하나의 원천 문항을 네이버 블로그의 700~1,200자 설명, Facebook의 이미지/투표, X의 280자 퀴즈, Threads의 팬 대화 질문으로 나눈다. 같은 문구를 그대로 복사하지 않는다.

## 4. 채널별 운영 계획

### 4.1 네이버 블로그

**역할:** 검색·신뢰·장기 자산. 사이트가 현재 `noindex`이므로 초기 검색 발견은 블로그가 대신한다.

- 빈도: 주 2편, 90일 24편.
- 형식: 질문형 제목, 3줄 요약, 문제/보기, 정답 근거와 기준일, 야구왕에서 한 이닝 풀기 CTA.
- 키워드 묶음: `야구 규칙 퀴즈`, `KBO 상식 퀴즈`, `야구 초보 규칙`, `한국시리즈 퀴즈`, `구단 역사 퀴즈`.
- 각 글은 독립적인 답을 제공한다. 클릭을 위해 정답을 숨기거나 같은 문장을 반복하지 않는다.
- 네이버는 게시물 노출을 보장하지 않으며 검색 의도에 맞지 않거나 유사·스팸 문서로 판단되면 노출하지 않는다고 안내한다. 따라서 키워드 반복보다 원본 설명과 출처 품질을 우선한다. [네이버 블로그 고객센터](https://help.naver.com/service/5593/bookmark/9564?lang=ko&osType=PC)
- CTA 링크: `?utm_source=naver&utm_medium=blog&utm_campaign=2026-11-fan-inning&utm_content={slug}`.

**30일 목표:** 8편 발행, 글별 조회/앱 클릭/첫 경기 완료를 기록. Analytics 도입 전에는 네이버 조회·링크 클릭과 앱의 완료 수를 같은 기간의 참고치로만 보고 직접 귀속이라고 부르지 않는다.

### 4.2 Facebook

**역할:** 구단 팬 그룹·연령 폭이 넓은 커뮤니티에서 대화와 친구 대결 모집.

- 빈도: 공식 페이지 주 3회, 관련 그룹은 규칙을 확인한 뒤 주 1~2회 이하.
- 형식: 네이티브 이미지 퀴즈, 투표, 20~30초 화면 녹화, 친구 대결 모집글.
- 게시물 80%는 링크 없이도 가치가 있어야 한다. 정답/해설을 본문이나 댓글에 제공하고, 링크 허용 그룹에서만 CTA를 붙인다.
- 그룹마다 홍보·외부 링크·반복 게시 규칙을 기록한다. 같은 글을 여러 그룹에 일괄 투하하지 않는다.
- 운영자가 댓글에 출처·기준일을 답하고 오답 지적은 수정 기록으로 남긴다.
- CTA 링크: `utm_source=facebook&utm_medium=social`.

**핵심 실험:** “한 문제 퀴즈” 대 “친구 4명 방 모집”의 첫 경기/방 참가 전환 비교.

### 4.3 X

**역할:** 실시간 야구 대화, 기록·규칙 팬, 빠른 퀴즈 검증.

- 빈도: 원글 주 5회, 하루 5개 내외의 의미 있는 답글. 같은 계정 원글은 약 60분 이상 간격.
- 형식: 1문제 퀴즈, 3~5개 포스트 해설 스레드, 경기/규칙 이슈에 출처를 더한 인용 포스트.
- 첫 8~10단어 안에 `KBO`, `야구 규칙`, `친구 대결` 등 구체 주제를 넣는다.
- 게시 후 30분은 답글에 응답한다. 좋아요보다 DM 공유·링크 복사·프로필 클릭을 부르는 “친구에게 내볼 문제”를 만든다.
- 기본 포스트는 280자 이내이며 긴 글은 유료 기능이다. [X 도움말](https://help.x.com/en/using-x/types-of-posts)
- 해시태그는 1~2개만 사용한다. `#KBO`, `#야구퀴즈`처럼 내용과 직접 관련된 것만 쓴다.
- CTA 링크: `utm_source=x&utm_medium=social`.

**핵심 실험:** 정답을 다음 포스트에 공개하는 퀴즈 대 즉시 해설형 포스트. 외부 링크 클릭뿐 아니라 답글의 실제 대화 품질을 함께 본다.

### 4.4 Threads

**역할:** 가벼운 팬 대화, 입문자·일상형 야구 콘텐츠, 운영자 인간성.

- 빈도: 주 4회, 댓글 대화는 매일 15분.
- 형식: 200~500자 팬 질문, 짧은 제작기, 구단 응원 습관, “친구에게 내는 문제”.
- 첫 1~2줄에 상황을 둔다. X의 압축 문구를 그대로 옮기지 않고 맥락과 감정을 조금 더 쓴다.
- 한 게시물에 주제 태그 하나만 쓴다. 공식 안내상 Threads 게시물은 최대 500자이며 링크·사진·동영상을 포함할 수 있다. [Meta 공식 소개](https://about.fb.com/news/2023/07/introducing-threads-new-app-text-sharing/)
- CTA 링크: `utm_source=threads&utm_medium=social`.

**핵심 실험:** “내 구단 이야기” 대 “야구 지식 문제”의 댓글률과 게임 시작률 비교.

## 5. 프로필과 고정 게시물

모든 채널의 이름·설명·링크 문구를 통일한다.

**바이오 초안:** `문제는 투구, 정답은 안타. 3아웃 한 이닝 KBO 팬 퀴즈 ⚾ 비회원 바로 시작`  
**고정글 초안:** `한 이닝은 3아웃까지입니다. 가입 없이 시작할 수 있고, 친구 대결은 링크 하나로 2~10명이 함께합니다. 점수는 비공식이며 문항마다 출처와 검증일을 표시합니다.`

공식 제휴·공식 랭킹으로 오해할 표현은 쓰지 않는다.

## 6. 친구 초대 바이럴 설계

야구왕의 바이럴 잠재력은 **중간~높음**이다. 개인 퀴즈는 혼자 끝나지만 친구 대결은 다른 사람이 참가해야 가치가 생기는 노출 루프다. 첫 90일은 금전 보상보다 자연스러운 초대를 우선한다.

### 6.1 현재 가능한 루프

`방 만들기 → 초대 링크 복사 → 친구가 링크 방문 → 비회원 이름 입력 → 2명 이상 참가 → 대결 완료 → 새 대결`

방 생성·링크 복사·비회원 참가·실시간 대결·최종 순위까지는 구현돼 있다. **공유 메커니즘 관점에서** 구현된 것은 원본 링크 복사뿐이며, 추천자 귀속, 채널별 공유 문구/버튼, 개인 결과 카드, 보상은 미구현이다.

### 6.2 우선 실험

| 우선 | 실험 | 제품 변경 | 성공 지표 | 중단/보완 기준 |
|---:|---|---|---|---|
| 1 | 주 1회 `금요일 친구 대결` 모집 | 없음 | 방 생성 수, 2인 이상 시작률, 완료율 | 시작률이 낮으면 초대 문구·시간 조정 |
| 2 | 링크 복사 뒤 채널별 미리 쓴 문구 제공 | 필요 | 복사→초대 방문률 | 4주간 초대 방문이 없으면 노출 위치 재검토 |
| 3 | 대결 종료 후 `재대결/새 친구 초대` | 필요 | 완료 방당 다음 방 생성 | 사용량·스팸 증가 시 제한 |
| 4 | 개인 경기 박스스코어 결과 카드 | 필요 | 결과 공유율, 공유 유입 완료율 | 이미지 권리·개인정보·OG QA 전 출시 금지 |

**초대 문구 초안:** `야구왕 친구 대결 열었어. 앱 설치 없이 이름만 적고 10문제 같이 풀자. 방 코드 {코드}`

### 6.3 보상 원칙

- 처음 90일은 현금·경품·공식 점수 보상을 사용하지 않는다.
- 초대 보상은 향후 `첫 친구 대결 완료`, `3명 참가`, `다른 구단 팬과 대결` 같은 명예 배지로 검토한다.
- 보상은 링크 전송이 아니라 **초대받은 사람이 대결을 완료했을 때**만 인정한다.
- 공식전·월간 등수 점수에는 추천 보상을 섞지 않는다. 다계정·스팸이 경쟁의 신뢰를 무너뜨릴 수 있다.

## 7. 구단별 경쟁 바이럴 설계

### 기본 루프

`회원가입·최애 구단 선택 → 출석 → 구단 대항전 집계 → 주간 순위 확인 → 같은 구단 팬 초대 → 신규 팬 출석`

### 운영 장치

1. 매주 월요일 “이번 달 구단 대항전” 요약을 4채널에 발행한다.
2. 참여 팬 3명 미만 구단은 순위가 보이지 않는 현재 규칙을 그대로 설명하고 “같은 팬 3명 모으기”를 CTA로 쓴다.
3. 순위는 출석 일수 합계임을 명시한다. 개인 연습 점수나 조작 가능한 점수로 경쟁시키지 않는다.
4. 구단명은 사실 정보의 글자만 사용하고, 허가되지 않은 로고·선수 사진·공식 컬러 자산은 쓰지 않는다.
5. 1위 구단 팬을 과도하게 띄우거나 하위 구단을 조롱하지 않는다. “다음 주 역전 가능” 같은 참여 언어를 쓴다.

### 캠페인 예시

- `우리 구단 첫 3명 만들기`: 순위 미표시 구단의 초기 참여 확보.
- `7일 출석 불펜`: 7일 연속 참여를 개인과 구단에 연결.
- `주말 더블헤더`: 토요일 친구 대결, 일요일 구단 순위 확인.
- `월말 3아웃 역전`: 마지막 3일 출석 리마인드. 과도한 푸시나 다계정 유도는 금지.

## 9. 주간 운영 루틴

- 월: 지난주 퍼널·상위 콘텐츠 3개·하위 3개 검토, 구단 대항전 요약.
- 화: 네이버 원문 1편 제작, X/Threads로 재가공.
- 수: Facebook 퀴즈/투표, 댓글에서 VOC 기록.
- 목: 두 번째 네이버 글 또는 기능 가이드, 친구 대결 모집.
- 금: 친구 대결 운영, 게시 후 30분 응답.
- 주말: 실시간 이슈는 출처 확인 뒤만 반응. 다음 주 문항 2개 검수.

주당 4~6시간을 넘으면 빈도를 줄인다. 지속할 수 없는 일일 발행보다 90일 동안 반복 가능한 주간 자산을 우선한다.

## 10. 채널 실험 판단 규칙

- 최소 4주 또는 채널별 100개 랜딩 세션 중 늦게 충족되는 시점까지 성급히 승패를 내리지 않는다.
- `게임 시작률`이 전체 중앙값보다 25% 이상 높고 두 번 이상 반복된 주제는 다음 달 비중을 늘린다.
- 클릭은 많지만 완료율이 낮으면 채널을 끊기보다 메시지-제품 기대 불일치를 먼저 점검한다.
- 댓글·조회만 높고 게임 시작이 없으면 인지도 콘텐츠로 분리하고 전환 성과로 포장하지 않는다.
- 신고·권리 이슈·스팸 반응이 발생하면 성과와 무관하게 즉시 중단하고 원인을 기록한다.
