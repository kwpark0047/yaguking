# 야구왕 30일 콘텐츠 발행 일정

**기간:** 2026-11-01 ~ 2026-11-30  
**목표:** KBO 팬에게 야구왕의 한 이닝 경험을 알리고, 친구 대결·구단 대항전을 통해 첫 완료와 재방문을 만든다.  
**운영 가정:** 1인 운영, 주 4~6시간, 유료 미디어 0원. 일정은 KBO 공식 일정·서비스 운영 상태에 맞춰 당일 조정한다.

> **기준선 반영(2026-11-01):** 가입자 2명 상태에서는 데이터 리포트형 글(11/05 구단 대항전 문구, 11/09, 11/16, 11/29, 11/30)을 [`05-baseline-reset-first-100-fans.md`](05-baseline-reset-first-100-fans.md) §5대로 바꿔 발행한다.

## 1. 발행 원칙

1. 검수된 문항과 출처·검증일이 있는 내용만 사용한다.
2. 실제 선수 사진·구단 로고·공식 영상은 권리 확인 전 사용하지 않는다.
3. X와 Threads, Facebook 문구를 그대로 복사하지 않는다.
4. 링크 허용 여부가 불명확한 커뮤니티에는 먼저 가치 있는 퀴즈/해설만 올린다.
5. 11월 5일 출석·공식전·구단 대항전은 실제 화면과 운영 작업을 스모크 테스트한 뒤에만 “시작”으로 발행한다. 열리지 않으면 “준비 중” 공지로 대체한다.
6. Analytics가 도입되지 않은 기간에는 UTM을 붙여도 방문 귀속을 확인할 수 없음을 내부 보고에 표시한다.

## 2. 제작 템플릿

### 네이버 블로그

`검색 질문형 제목 → 3줄 요약 → 퀴즈/보기 → 정답 → 규정·출처·기준일 → 야구왕 한 이닝 CTA`

### Facebook

`이미지 1장 또는 짧은 네이티브 영상 → 문제 → 댓글 참여 → 정답·출처 댓글 → 허용 시 링크`

### X

`첫 8~10단어에 구체 주제 → 문제/주장 → 1개 행동 → 게시 후 30분 응답`

### Threads

`팬 상황 한 문장 → 개인 경험/질문 → 짧은 맥락 → 자연스러운 CTA → 주제 태그 1개`

## 5. 게시물별 기록 시트

| 필드 | 예시 |
|---|---|
| 게시일/채널 | 2026-11-05 / Threads |
| 콘텐츠 ID | `d05-engagement-launch` |
| 기둥 | 구단·친구 대결 |
| 제작 시간 | 35분 |
| 링크 | UTM 포함 최종 URL |
| 플랫폼 성과 | 노출, 댓글, 공유, 프로필 방문, 링크 클릭 |
| 제품 성과 | 신규 방문, 게임 시작, 게임 완료, 가입 완료 |
| 품질 | 정정, 신고, 부정 반응, 문의 |
| 결정 | 반복/수정/중단과 이유 |

Analytics 도입 전에는 플랫폼 지표와 제품 지표를 직접 연결하지 않는다. 링크 클릭과 같은 시간대 완료 증가를 관찰하더라도 “상관 참고치”로 표시한다.

공개 리포트는 표본이 작거나 구단별 참여자가 3명 미만이면 수치를 생략하고 “집계 중”으로 표현한다. 내부 대시보드의 원수와 공개 가능한 집계를 구분한다.
